## Purpose & Hypothesis
exp72–100 把"单局点差 + 镜像自对弈 + 2M 参数 CNN"设定下的七类算子（策略梯度 / 价值自举 / 搜索 / 探索结构 / 奖励塑形 / 人口 / 目标函数）全部量过，均衡 ≈0.45–0.46（Q1x 0.4568 @112M）。
没动过的两个轴是 AlphaZero 真正依赖的：**规模**（缩放律每翻倍 +1.5–2 pp，exp75；64–80M 处退火实验显示曲线在弯，exp80）与**容量**（exp78-B 2× 参数在 32M 从零无增益，但那是数据不足区间）。
**H1**：2× 容量 + 3.5× 于 Q1x 的局数（400M）把纯血线推到 **T=0 对 bc49 ≥ 0.50**（总目标，20k 对双段）；中间里程碑 ≥0.48 算"规模仍在兑现"。
**H0**：112M 处不高于 Q1x（≤0.452）且曲线斜率不高于 cnn_m 的 ⇒ 容量轴不兑现；转规模单轴（见判据 3）。终点 ≤0.47 ⇒ 规模轴也已饱和，纯血线在此设定下的天花板确认为 0.46–0.47。

## Method
- **配方**（exp79/81/88 谱系，只改架构与总量）：`--engine rust --arch cnn_l_v3r`，从零；`--entropy_coef 0.03 --entropy_schedule 0:0.03`（Q1x 的常熵 0.03；exp79 的 0.03→0.01 退火在 exp88 被高熵反超）；
  `--shaping --shaping_schedule 0:1.0,400000:0.0`、γ 0.995、λ 0.95、batch 4096、dup_k 8、games_per_iter 2048、target_kl 0.03、adv_clamp 5、ppo_epochs 1。
  学习率分段（exp78 的 1e-4→3e-5 是 +1.6 pp 的来源）：**阶段 1** 0→64M lr 1e-4；**阶段 2** 64M→终点 lr 3e-5（`--resume`，新 exp_dir 后缀 `_p2`，同 GCS 命名空间）。
- **总量与预算**：目标 **400M 局**；机器优先 Secure RTX 2000 Ada（$0.24/h，≈575 局/s ⇒ ≈193 h ≈ $46），无货则 Secure 3090（$0.50/h ⇒ 400M ≈ $97，届时目标降为 **250M** 并把判据 3 的决策点提前）；
  **总上限 $100**（含坏宿主损耗；评测全在本机 $0）。花费按 pod 计时累计记入 Progress。
- **监控**：心跳（18 h 窗口，到期重挂）、拉取 + GCS + TB 镜像、在轨循环（每 8M：对 M / bc49 / Q1x n=1000/500 + 弃和探针 + 牌类探针 + 分巡目读数）；`latest.pt` 每 400 迭代；pod 失效即从 GCS/本地最新 ckpt `--resume`。
- **对照曲线**（已有，同配方 cnn_m）：X32/V 32M 0.4293/0.4394、W 64M 0.4468、M 80M ≈0.45、Q1x 112M 0.4568（终评口径）。里程碑 32M/64M/112M 做 **20k 对终评口径**的 vs bc49（本机，$0）以便与对照曲线同刻度比较。

## Success Criteria（预注册）
1. **健康**：32M 处 vs bc49（20k 对）≥ 0.42（V 0.4394 − 2 pp）；熵不塌（≥0.6 nat）；KL 常态。破线 ⇒ 排查配方后重发或停。
2. **里程碑判读**（20k 对口径）：64M ≥ 0.44（W 0.4468 − 0.7 pp 内）；**112M ≥ 0.462**（Q1x + 0.5 pp）⇒ 容量轴在兑现，继续；112M ∈ (0.452, 0.462) ⇒ 中性，继续（规模轴仍未测）；112M ≤ 0.452 ⇒ 判据 3。
3. **容量轴判负时的转向**：停止 cnn_l 臂，用剩余预算把 **Q1x（cnn_m_v3r）从 112M 续训**到预算耗尽（lr 3e-5、熵 0.03、无塑形），每 50M 一次 20k 对读数——纯规模轴。
4. **终点**（400M 或预算 $95 处）：T=0 对 bc49 双段 20k 对 **≥ 0.50 → 总目标达成**（再跑半庄 n=1200 ≥ 0.50 才加冕纯血冠军）；0.48–0.50 → 规模仍在兑现，报告并按延长规则申请；≤ 0.47 → 天花板确认。
5. **延长规则**（用户 09-12）：终点前最后两个里程碑（间隔 ≥50M）仍单调上升 ≥ +0.5 pp ⇒ 报用户申请追加预算，不自行越 $100。
6. 所有在轨读数（n=500/1000）只用于健康与早停，判决只认 20k 对口径。
