## Purpose & Hypothesis
论文需要一个"外部强规则 / 搜索型 AI"参照行：akochan 在与 exp124 判决相同牌山上的单局复式份额（对 bc49）。描述性。

## Method
- 牌山：标准 10,500 判决牌山的**前 2000 个**（101112000–101113999），T=0 复式 2v2，A = akochan（两个座位各一个 `system.exe pipe` 子进程，每局新开），B = bc49 T=0。驱动与 L1 相同的牌山 / 场况生成（已对存档 300/300 校验）。
- **tactics 改动（只改配置）**：`tactics_points.json` = 官方 `setup_mjai.json` 只把 `jun_pt` 从 `[90, 30, -30, -90]` 改成 `[0, 0, 0, 0]`（单局点差目标，不计顺位点）；其余字段逐字相同（`tactics_default.json` 为原样副本）。
- `start_game` 附加 `kyoku_first: 4, aka_flag: true`（akochan 必需字段）。
- 线程：每进程 `OMP_NUM_THREADS=4`，6 进程并行（避免 24 核超订）。
- **桥校验**：前 300 牌山（600 局）单独统计回退率（akochan 动作不在引擎合法集）与非法率；预注册门槛：回退率 < 0.5%。
- 扩展规则（论文会话指定）：2000 牌山份额在 0.50 ± 3 pp 内才扩到全部 10,500。
- 可选：500 场复式半庄（L3 协议、种子 201000000、akochan 默认顺位 tactics）——仅当主行完成后算力允许。

## Success Criteria
桥校验回退率 < 0.5%；描述性报告份额 ± SE、每牌山点差。

- [2026-11-07 19:05 PST] **根因（作废）**：akochan 的目标函数 = Σ 名次概率 × `jun_pt`（`ai_src/selector.cpp` 155、203 行：`kyoku_end_pt_exp += jun_prob[my_pid][j] * tactics.jun_pt[j]`），只看最终名次分，不看点数本身。本实验把 `jun_pt` 改成 [0,0,0,0] 想得到"单局点差目标"，结果所有选项的期望都恰好是 0，等于随手打（追踪：手里 789m 完整、345m 两面，却依次切 3m、摸到的 4m、5m、7m、8m）。是本预注册的设计错误，不是 akochan 的问题。**第一轮结果作废，不得引用**（分片保留在 `probes/akochan_dup/`，已标作废）。
- **修正方案**：用官方 `setup_mjai.json` 原样（`tactics_default.json`，`jun_pt` [90, 30, −30, −90]，名次目标），与 L1 的 Mortal 行同口径（Mortal 也是按其原生名次头打）；`ai_src` 仍不改。在单局份额上解读时注明：akochan 优化的是半庄名次（以随机化的场况 / 点数为起点），不是单局点差。
- **红五回退调查**：8 次全是"akochan 要打普通 5s，手里只有赤 5s"。`mjai_export` 在起手、摸牌、打牌、鸣牌事件里都正确拼写赤五（`5sr`）；可疑路径是吃 / 碰：两个桥（akochan、Mortal）都把对方请求的 consumed 转成普通拼写、由引擎自己决定用哪张，若与 akochan 的预期不同，它对自己赤五的认知会偏离。Mortal 在 619k 决策里 0 次，可能是它的请求顺序恰好与引擎一致。重跑时桥加了 `AKO_FALLBACK_LOG`：每次回退把该座位本局全部事件 + 引擎手牌写入文件，以定位确切路径（只改本目录的桥，不改 `ai_src`、不改其他 run 用的代码）。

- [2026-11-08 03:10 PST] 重跑中第一条回退转储（分片 4）确认红五路径：座位 0 起手有普通 5s、又摸到 `5sr`（两张 5s 一红一普）；吃 7s 时 akochan 请求的 consumed 被桥统一转成普通拼写，引擎于是用掉普通 5s、留下赤 5s，导出的 chi 事件也如实写 consumed `["5s","6s"]`；之后 akochan 仍要打"普通 5s"（引擎只剩 `0s`）⇒ 回退。即 akochan 内部手牌跟随了它自己请求的那张（推测为赤 5），而不是事件里的实际 consumed。修正方案（本轮跑完后再改，只动本目录的桥）：吃 / 碰时把 akochan 请求的 consumed 按原拼写（含赤）传给引擎，让引擎用 akochan 指定的那张。影响：每 1.6 万决策约 1 次，对份额可忽略。
