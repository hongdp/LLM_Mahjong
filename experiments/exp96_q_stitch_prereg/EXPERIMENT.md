## Purpose & Hypothesis
用户问题（09-20）："为什么一直探索 policy gradient 而不是 value based？"——历史上三次价值方法（exp59 先验上 DQN、exp60 演员-学习者、exp71 从零 DQN 0.17）全部不如 PPO，
但 exp94 给出了一个恰好落在两类方法分界线上的事实：**"远手切安全牌"在 M 自己的续打下价值 ≈0（单步建议 +65 n.s.），在好续打下 +258 ± 44 分/决策**。
PPO 估的是 A^π（换一步、之后仍按当前策略），该量 ≈0 ⇒ 无梯度；Q 学习的目标 r + γ·max Q(s′,·) 估的是"之后按最好续打"的价值，
原则上能把不同行为策略的轨迹片段缝合（听牌时 M 的推、远手时 P4/E 的连续安全牌）。

exp59/71 的两个已诊断病因，本实验逐一对症：
1. **Q 回归侵蚀动作排序**（回报 σ≈2–5k 分 vs 牌效近似并列动作的价值差几十分；exp59 去锚掉到 0.21）→ **先验锚定**：
   Q(s,a)=V(s)+A(s,a)，A 头末层**零初始化**；行动与自举算子都是 a\*=argmax_a[log(π₀(a|s)+ε)+A(s,a)/τ]（π₀=冻结的 Q1x）。
   A=0 时逐位等于 Q1x；τ 把"分数"换成"nat"（τ=0.05、reward_scale=0.5/千点 ⇒ 100 分 ≈ 1 nat）：30 分的噪声只是 0.3 nat 的扰动，
   300+ 分的真优势才能推翻先验——攻守决策正是大价值差的那一类。ε 保证任何合法动作付有限代价即可被选中（预注册初稿 ε=0.02，发射前改 0.003，见 Progress）。
2. **单一行为策略没有可缝合的续打覆盖**（exp59 数据全是 bc49 自己 + 单点偏离；exp71 全是自己）→ **混合行为人口**：
   每席独立抽 学习者 55% / Q1x 10% / M 5% / P4 10% / E 10% / 规则弃和包装器 F 10%（有对手立直且自己未听牌时，把弃牌掩码限制到对全部立直者的现物），
   四席轨迹全部入回放（同编码、同动作空间）。

**H1**：终点 T=0 对 bc49 单局 ≥ 0.47（20k 对双段；Q1x 0.4568，+1.3pp ≈ 3.7 SE），且机制读数同向（见判据 2）。
**H0**：≤ 0.46（与 Q1x 不可分）或机制读数不动 ⇒ "自举缝合"在纯血人口的行为支撑上也取不到 exp94 的那笔钱，价值方法线在纯血线第四次关闭。

## Method
- **网络** `aq_cnn_m_v3r`（`AnchoredQPolicy`，新）：`prior`=冻结 Q1x；`q`=Q1x 副本（trunk 可训，`head` 末层置零 → A，`value` 头 → V）。
  A 以 π₀ 加权均值中心化（V = E_{π₀}Q）。`forward` 返回 log(π₀+ε)+A/τ（掩码后），所以所有现成评测/探针/桥接把它当普通策略网加载。
- **训练器** `scripts/train_dnn_qstitch.py`（新；复用 exp59 `Replay` 环形缓冲，planes 改 uint8）：
  收集用 Rust VecEnv（`collect_rust` 同款循环，按 seed 确定性抽席位行为；学习者席与各冻结网 T=1 采样，F 席用 VecEnv 新接口 `safe_info()` 的现物掩码）；
  奖励=原始单局点差（无塑形、无放铳惩罚）×0.5/千点；γ=1（单局有限期）。
- **目标**：先 MC 校准（V/A 对行为回报回归）30 万局，之后 **n=3** 步锚定 Double DQN：y = R₃ + Q_target(s′, a\*_online(s′))；Huber；硬同步每 1,000 更新；
  lr 1e-4（trunk ×0.3）、batch 1024、回放 4M 步、replay ratio 1。n 取小是设计要点：n 大时目标 ≈ 行为策略的 MC 回报（Q^μ 的混合），只有自举的 max 才缝合。
- **TB 诊断**（回放里存 立直对手数/自家向听）：|A| 均值、锚定贪心≠先验贪心的**改判率**（全体/暴露态/暴露且远手）、暴露远手态上 A(最优现物) − A(先验选择)。
- **预算**：社区 RTX 4090（≈$0.35–0.6/h）≈10 h；发射前用冒烟吞吐把"10 h"换算成固定局数写入 Progress。**≈$5，上限 $6**；延长规则触发时总上限 $8。
  项目累计 ≈$88/$200（含 exp95 两臂）。
- **对照（条件执行）**：主臂落 H1 或中间带时才跑 n=10 臂（同配方），用来区分"自举缝合"与"只是 Q^μ 评估 + 锚"；主臂 H0 则不跑。

## Success Criteria（预注册）
1. **主判据**：games_final（T=0，τ=0.05）对 bc49 单局双段 20k 对（67M n=4000 + 68M n=16000）≥ 0.47 → H1；≤ 0.46 → H0；之间=中间带。
   目标线（总目标）：≥ 0.50 且半庄 n=1200 ≥ 0.50。
2. **机制判据**（bc49 桌，终点）：放铳率 ≤ 0.13 且和牌率 ≥ 0.19；牌类探针 向听≥2 生牌率 ≤ 0.20（Q1x ≈0.30，bc49 ≈0.10）；
   接管探针 T−A 从 +258 缩到 ≤ +150 分/决策（1,000 局）。
3. **健康**：MC→TD 切换后 q/target 不发散（|Q|<3）；改判率全体 ≤ 15%（锚没被冲垮）；对 M 在轨不低于 0.47。
4. **在轨读数**（n=500，不作判决）：每 50 万局对 M/bc49 + 弃和探针 + 牌类探针；早停仅限健康判据连续两点破线。
5. **延长规则**（用户 09-12 规则，给够训练时间）：终点对 bc49 ≥ 0.46，或末四分之一程内 向听≥2 生牌率仍下降 ≥0.02 且和牌率不掉 ⇒ 追加 50% 局数（总上限 $8）。
