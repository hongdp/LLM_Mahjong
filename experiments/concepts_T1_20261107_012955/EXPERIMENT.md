## Conclusion
- **涌现点：大体稳健，但不是"完全一致"**（2026-11-07 15:00 更正：原稿此句是按水平目测、未用预注册判据，论文会话复核指出）。用预注册判据（`scripts/analyze_concepts.py`，|z|≥3 连续成立 / 绝对阈值）对 T=0 与 T=1 各跑一遍，15 项里 **11 项涌现点相同**：向听最优 4M、宝牌 4M、客风先切 4M、碰役牌 4M、现物 iq 与 iq−安慰剂 4M、字牌 4M、筋∪壁 / 筋 8M、好型−愚型 16M、对手立直 16M、无役立直 56M。**4 项不同**：
  - 早巡−晚巡：T=1 8M，T=0 16M（早一个检查点）；
  - 切赤五（绝对阈值 < 0.10）：T=1 从不满足（采样下切赤五率 0.07–0.18），T=0 4M——绝对阈值本身对温度敏感；
  - 中筋：T=1 128M，T=0 16M——T=1 下 16–120M 多数检查点 n < 100，z 自 16M 起 ≥ 2.5 但未连续 ≥ 3；
  - 壁：T=1 从不，T=0 24M——同样 n < 100，88M / 120M z 只有 1.6 / 1.7。
  后两项主要是样本量不足 + T=1 水平更低造成的判据未过，不是概念消失；但按预注册判据只能写"T=1 下未确认"。CNN 结论不变：392M 仍无条件立直（好型−愚型 .006），现物弃和停在 0.12–0.16。
- **水平：T=1 普遍低于 T=0**（采样稀释偏好）：iq −0.02～−0.06（**T=1 下 144M 的 iq−安慰剂 0.240 与 bc49 0.238 持平**，原始 iq 0.155 vs 0.176、−1.8σ ⇒ "弃和领先 bc49"只对贪心解码成立）、立直对比 −0.02～−0.09、受入最优 −0.10～−0.15；最弱的偏好**客风先切在 T=1 几乎被抹平**（.35–.46 → .10–.17）；鸣牌在 T=1 更多（门清碰非役牌 +0.07～+0.09）。bc49 同方向但幅度小（其策略更尖锐）。
- 注意：A 0M 在 T=1 的 iq−安慰剂 .357 是随机策略下触发样本极少的噪声（T=0 无样本），不作解读。
