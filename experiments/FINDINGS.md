## 2026-08-24 候选配方：handset + 恒定低熵 = 自组织分阶段探索（首个"有效 recipe"候选）
exp31-4ext（handset_xl，熵系数恒定 0.01，无 schedule，2.0M 局）观察到完整的自组织探索周期：
熵平台 ~0.7（孵化）→ 立直风格成型 → 熵降至 0.51（变现，T1 1044.4@1.6M，超冠军 schedule 配方 1031.9）→
**熵自发回升 0.52→0.60，第二次转型**（副露率 0.11→0.3、和牌率/速度同步改善）。
意义：探索节奏不再需要手工 schedule——表达力足够的架构（set-attention）在恒定系数下自己分阶段调配探索。
反例警示：cnn_xl 同系数崩盘（851.7）→ 该性质是架构相关的，不是"调低系数"就行。
确认门槛（未过完不许写进 README 结论）：① 2.0M 收官 T1；② exp31-6（cnn_m 恒定格）归因；③ exp35 种子复刻；④ 大模型 exp34 复现。

## 2026-08-25 派生特征（向听/进张/听牌候选）在从零自对弈中是显著负收益
exp41 两臂唯一差异是输入是否含预算好的牌效分析：**A（有）924.4 vs B（无）998.3，
差 −73.9 ≈ 4.8σ**。机制在风格里看得很清楚：拿到向听数 ⇒ 贪心最小化向听 ⇒ 副露最快推进向听

## 2026-08-27 exp45：人类牌谱 BC 一天改写三条定论

- **exp10 的「BC 保真度不兑现强度」是弱教师伪象**：自家启发式教师 81-90% 就饱和、测不出架构差异。
  换凤凰卓人类数据后，BC 精度直接兑现为 Elo（+4pp→+90），精度冠军=强度冠军。诊断性结论受限于
  数据源难度——教师太弱时"无差异"不可信（与 SKILLS:106 探针要带正对照同理）。
- **样本效率的量纲**：2000 局人类牌谱 + 30 分钟 BC ≥ 2,000,000 局调优自对弈 RL（cnn_m 1043.6 vs 1052.1；
  Mortal 设计 1147.4 vs 自身从零 998.3）。人类示范每局的信息量约等于自对弈的千倍。
- **防守只能从示范来（exp21 结案）**：六个 BC 臂 defense_iq 全过 0.03（历代自对弈最高 0.016）；
  HRF 0.172 且弃牌随手牌强度条件分化。单局自对弈目标给了防守定价（放铳扣分）但优化路径给不出
  行为——押退是 ~10 手协调宏观行为，反事实奖励 + 微观探索采不到（同理支持 exp43 的节奏假设）。
- **从零自对弈下的架构定论不可外推到示范数据 regime**：exp41 判 Mortal 设计 998「不及冠军配方」、
  exp30/36/37 判 HRF 852-896「架构上限」——同样的网络吃人类数据后一个登顶 1147、一个成防守之王。
  架构结论必须绑定训练信号源声明。
- **未收敛不比较**（用户抓的）：固定 4 epochs 会把 ConvFormer（17 epochs 收敛、起跑落后 1.2pp）的
  H1 信号判成 null。跨架构比较一律用同一早停规则跑到各自平台。

## 2026-08-28 exp49：数据缩放三定论

- **小数据点的架构排序不可外推**：v3r+46 组合在 2000 局垫底（1134.9）、18.4k 局登顶（1191.4 池史新高）。
  设计比较必须在目标数据量上做终审；10% 筛选只用于淘汰、不用于加冕。
- **容量叙事第三次阵亡（终审）**：11M SEres 在 9× 数据 + 独立 lr sweep（1e-4/cosine 均 <+0.1pp）后
  仍全面不敌 2M ConvFormer。本项目范围内"更大=更强"在 BC 与 RL 两个 regime 都不成立，
  结构（注意力/局部性先验）才是兑现变量。
- **BC 数据缩放汇率**：10%→100%（9×）= +3.7-4.0pp 精度 = +27~57 Elo = 防守 +0.03-0.07，
  20k 局未见饱和——数据扩容（10 万局级）是当前最高期望值杠杆，届时回放管线需做 3-5× 优化
  （解析缓存/4 座共享/小变体物化）。

## exp46 C~J 收官要点（2026-08-30，供状态快照）
- A/B 的"RL 净毁值"仅适用于修复前的训练器。四条已修病因：①价值梯度经共享 trunk 扰乱策略（修复 `--value_detach`，唯一让 pg_loss 转负的干预）；②熵扩散（噪声追逐的内生熵增；锚是唯一有效熵控制器，熵奖励既不必要也不充分，已默认 0）；③优势对称 clamp 审查放铳尾部（已默认去除）；④**T=1 族内评分对部署强度严重失真**（I：族内 -9 同时贪心头对头 +48）——终审一律 T=0 + 族外梯子 + 半庄 n≥300。

## 2026-08-30 exp56：半庄裁决刻度的四条定论

**背景**：向量化 GPU 半庄接通（967 场/分，对 batch-1 的 27/分 = 36×，逐场 uma 与 batch-1 驱动
完全一致），半庄从"一个候选打满锚池要 89 分钟"变成常规刻度，才有了下面这些量。

- **RL 相对 BC：裁决刻度上打平，不是增益（判据未达成）**。exp46-I vs bc49，**双方 T=0**、
  4000 场半庄：逐场胜份 **0.5141±0.0079（z=1.79）**，pt 幅度 **+0.85±0.47 /人/半庄**。
  四把尺子（逐场符号 / 复式对 / 纯顺位 / pt）方向一致偏 I，**没有一把过 2σ**。
  预注册的"≥0.53 才算有优势"未达成，"≥0.50 不劣于"达成。与单局刻度的 0.5005±0.0158 同向，
  半庄把它放大了但仍不显著。**exp46 的"打平不增益"判词在裁决刻度上被确认，不是被推翻。**

- **采样税不是常数，它按强度变号**。同一批 13 个模型，T=1 池评分减 T=0 池评分：
  bc51 −103 / exp46Cb −109 / bc49 −71 / exp27A −71 / exp46I −59，而弱锚**反向**：
  ppo44_600 **+191** / rf600 +126。**采样噪声对弱模型是净伤害、对强模型是净保护**。
  推论：v1「候选 T=0 对锚 T=1」不只是绝对值偏高，它**按强度扭曲整条刻度**，
  此前记录的"bc49 采样税 ≈ +29"只是这条曲线上的一个点。
  副产品：全贪心把池子跨度从 1035 收到 781，零封对从 19/78 降到 9/78。

- **单局→半庄放大 ≈2.5×，exp53 的 1.8× 作废**。同一批对局同时按两种口径计分证明：
  bc49 vs exp27A 在**现行规则 + 逐场口径**下是 **+242.2**，与 exp53 的 +246 吻合——
  **半庄规则修复（连庄/流满）对强度读数影响 ≈ 0**；1.8×→2.5× 的差额**全部**来自
  exp53 拿"逐场半庄"对比"复式对单局"的跨口径比较。

- **人类先验 ≫ 纯自对弈，量级已钉死**：bc49 对 exp27A 双 T=0 4000 场，胜份 **0.7966±0.0063**，
  pt 差 **+22.7/人/半庄**。

**北极星**：Mortal 对 bc49 半庄 n=300（现行规则，零 fallback）胜份 0.5417±0.0288，
pt **+2.40/人/半庄**；顺位分布上差距远比胜份显眼——**首位率 29.8% vs 20.2%、四位率 22.7% vs 27.3%**。

## 2026-09-02 exp60 第 2 轮：分布式价值训练系统定型；强度不变，晋级判据暴露非传递性（详录 exp60_value_league_prereg + designs/design_distributed_value_training.md）
- **设计定稿（每条有数据）**：GPU 演员（CPU 8 核即饱和 25 局/s，CPU pod 54 vs GPU 66–180 局/s/$，否决）；
  演员按"保证核数/价格"选型（L40S 13 核 65 局/s 配不上其 GPU 价；3090 secure 32 核最优）；学习者 batch 1024 bf16
  （512 起算力饱和，bf16 +50%，L40S 22–30k 样本/s）；数据层 = 学习者本地盘，跨 DC rsync lag 1–11s（pod 零凭证）；
  持久化 = 工作站拉取 + GCS 镜像；权重回传 <10s 非设计变量；解码 194k 步/s 非瓶颈。
- **拓扑配比**：一台 L40S 演员喂一台 L40S 学习者有效回放比 8——学习者饿；应 1 学习者 : 2–3 台 L40S（或 1 台 32 核 3090）。
- **演员吞吐随池子多样性衰减**（2→6 模型：62→34 局/s，GPU 推理服务器按模型分批）→ 每桌对手 ≤2 个模型。
- **强度**：88 分钟 / 87k 更新 / 203k 局 / 10 代晋级；n=4000 终评 gen_0002 **0.4993**（打平）、gen_0008 0.4894、gen_0010 0.4859
  vs bc49（A/A 0.500）。与 exp59/第 1 轮同一结论，且长跑后期轻微下滑。
- **判据教训**："对上一代 ≥0.5"在 n=2000（±0.011）下是掷硬币，绝对刻度 0.5075→0.4859 一路下滑而冻结规则（连续两次 <0.48）
  从未触发。晋级判据须以固定锚绝对刻度为主。
- 成本：$4.3 / 203k 局 ≈ $21/百万局（本轮配比失衡）；平衡拓扑估 $7–11/百万局。对局库 12.4M 步已落地，可 0 元离线消融。

## 2026-09-01/02 exp59：价值方法 v1（DQN on bc49 先验）——能学、不毁值、不超越（详录 exp59_dqn_value_prereg）

- 七臂 + 正式 200k 局（RunPod，$0.30）：**有 DQfD 锚的所有配方贪心 vs bc49 = 0.49–0.50**（n=1000–4000，
  T=0 单局复式对，A/A 对照 0.500）；无锚 0.21（v1.1 冻结行为 / v1.3 冻 trunk 头-only）、校准后去锚 0.447（−6.7σ）。
- 机制：热启动的 log-概率头回归到回报尺度时被 σ≈0.8 的样本噪声覆写排序；纯 TD 在这个样本量不含排序信息，
  锚 = 唯一防线且兼任过估计控制；头-only ≈ 全微调 ⇒ 参数量非变量；单点偏离 / 在线采集 / 四席数据都未动针
  ⇒ 病根是覆盖 + 样本效率（(σ/Δ)²），下一杠杆 = 配对牌山差分。
- 训练器两处 bug 修复（MC→TD 目标网同步；MC 期按更新数计）。方法论：新指标先跑 A/A；
  ±0.016 的 1000 对读数不足以判 >0.5。
- 后继：exp60 演员/学习者解耦 + 历史 ckpt 联赛 + 持久对局库（58 B/步）。

## 2026-08-30 exp57：RunPod 性价比裁决——换机（详录 exp57_runpod_cost_prereg）

- **旧成本表的两条地基都错**：①「5.8 局/s/核线性到 48 核」——实测曲线非线性，24 核处
  每核效率只剩单核的 42%，单 run 在单推理服务器栈上逼近 ~300 局/s 平台（GPU 峰值 39%，
  往返结构瓶颈）；②「3090 community 16 核/卡」——GraphQL 实查最低价宿主只给 8 核。
- **但方向对 RunPod 更有利**：3090 Ti community（$0.27/h，cgroup 23 核保证，EPYC 7663）
  实测 cnn_m_r K=32 **214.5 局/s（46w 超订 232.9）= 794 局/s/$ = g4-48 flex 的 6.4×**；
  handset_xl 62.4 局/s = 每美元 3.3×；每核速率 9.3 局/s/核反超 g4 核 1.6×。
  探针总花费 $0.12。
- **裁决**：默认训练机 g4-standard-48 flex → **单卡 3090 Ti community**；单 run 墙钟 77%、
  单位钱 6.4×，1M 局 rollout ~$0.50。多臂实验开多个 pod（吞吐随 $ 线性堆）。
  迁移前必补：community 长跑可靠性 + `--resume` 演练、训练全链路实测、库存（3090Ti 仅 Low）。
- **方法论**：秒级吞吐基准必须双长度差分消固定启动（v1 整条曲线是 3.4s 启动的摊销假象）。
