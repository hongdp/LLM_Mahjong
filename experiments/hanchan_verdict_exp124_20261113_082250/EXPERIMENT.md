- 指标：每 A 座位每半庄 uma（diff / 8），SE 按场聚类；场胜率（match-win）。

## Conclusion
**范围戳**：`convformer_m_v3r_m46` 2.0M，纯自对弈 PPO（exp124 A + Stage 2 流式续训），单训练种子；评测 = 2v2 复式半庄对 bc49、双方 T=0、3,000 场、本项目引擎半庄规则；
失效条件 = 换训练种子、换对手（族外梯子 / Mortal）或换桌型（四方混桌）后不复现。

1. **256M 的加冕判据在半庄刻度也满足**：+755 ± 204 uma / 座位 / 半庄（z 3.7）。11-12 的加冕现在单局、半庄两个刻度都有显著为正的头对头。
2. **四个检查点在半庄刻度都显著高于 bc49**，192M 已经是 +681 ± 202。此前唯一的同口径读数是 160M 的 −169 ± 292（share_to_uma，1,500 场），
   所以纯血线在 160M → 192M 之间越过了 bc49 的半庄水平，与单局刻度越线的位置（192M 0.5113）一致。
3. **半庄刻度上 256M 相对 192M 没有可分辨的提升**（+73 ± 272），而单局刻度是 +1.09 ± 0.43 pp；走势不单调，224M 和 288M 都高于 256M。
   288M 是四点里最高的（+1,599 ± 202，比 256M 高 +844 ± 265，z 3.2）——这是四个检查点里事后挑出的最大值，按预注册只描述、不下判决；
   288M 是否应取代 256M 需要 288M 对 256M 的直接头对头，放到 320M / 384M 判决里一起定（那两个里程碑的半庄已挂自动触发）。
4. **320M（11-13 自动补）读 +1,428 ± 199，与 288M 同档**（差 −170 ± 258），比 192M 高 +747 ± 267（z 2.8）、比 256M 高 +674 ± 268（z 2.5）。
   288M 不再是孤立的高点：连续两个后期检查点都在 +1,400–1,600，256M 的 +755 是五点里偏低的一个。单局刻度没有同样的台阶（320M 对 256M −0.46 ± 0.41 pp），
   所以对冠军 256M 的直接头对头提前到本轮跑：`experiments/h2h_champion_exp124_20261113_094928/`。
5. **384M（11-15，Stage 2 终点）+1,551 ± 202，三个后期检查点（288 / 320 / 384M）都在 +1,400–1,600**，比 192M 高 +870 ± 273（z 3.2）。
   但三者对 256M 的直接头对头都没分出胜负（半庄 +315 / +60 / +82 uma，单局 0.4959 / 0.5018 / 0.4976），单局刻度对 bc49 也停在 0.518–0.523。
   结论：半庄刻度对 bc49 的台阶是对手特异的（后期检查点更会打 bc49），不是可传递的强度提升；冠军不变。
