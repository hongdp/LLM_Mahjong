## 勘误（2026-11-06 10:10 PST，论文会话发现"76,255 局里没有一次双响"）
记录器只抓 mjai 流里的 hora 事件，而 `mjai_export.play_game_mjai` 有两处与引擎结算不一致（**只影响事件流，引擎点数结算正确**）：
1. **双响 / 多家荣和只发一个 hora**（`executed[0]`）：引擎 `_resolve_claims → step_ron` 按 RCR 3.11 结算所有宣告者，事件流只报第一个。
2. **本家回合任何终局都发 `hora(actor=target=本家)`**，包括九种九牌等途中流局（400 局抽查：4 局"tsumo"实为九种九牌；荒牌流局不发 hora，正确）。
用已存的逐局前后点数修正（$0，不重跑）：自摸 = 记录的自摸且本家点数增加（途中流局四家点差全为 0：A 525 / B 228 / C 232 局，全部满足）；荣和赢家 = 记录的荣和局里除放铳者外点数增加的所有座位（双响局 A 262 / B 112 / C 114，占荣和局 1.15–1.29%）。放铳率不受影响（每局一个 target）。
