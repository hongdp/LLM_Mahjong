# dnn_exp37_hrf_lr6e5_20260824 — HRF 单变量归因：仅降 LR（1e-4 → 6e-5）

- **Date**: 2026-08-24  **Cost**: G4 flex ~$15（1.0M 局 @ ~40 games/s ≈ 7h）  **Status**: launching
- **对照 = exp30**（`hrf_xl_v4`，warmup 150，lr 1e-4，1.0M 局 → T1 852.1±12.4）。
  **唯一变量 = `--lr 6e-5`**；warmup 保持 150 与 exp30 对齐，熵机制保持冠军 schedule 与 exp30 对齐。
  （用户要求单变量归因；exp36 那条恒定低熵线不参与本次对照。）

## 诊断依据（为什么是 LR，不是 warmup、不是局数）
1. **不是欠训练**：exp30 从 460k 到 962k 横盘 50 万局（878→851，中途甩到 932/829）；
   exp36 相邻检查点（隔 5 万局）甩动 ±100。**震荡形状 ≠ 缓慢爬升形状**，加局数只会继续震荡。
2. **不是 warmup 为主**：每迭代约 40 个优化器步（16.3 万样本 / batch 4096），
   warmup 150 只覆盖 3.75 迭代 ≈ 7,700 局 = 1M 局训练的 **0.4%**，无法解释全程偏高的稳态 KL。
   （exp36 漏传 warmup=0 是操作失误，已记录，但非主因。）
3. **不是参数量**：handset_xl **20.1M 参数**（21 LayerNorm / 10 注意力块）在同 LR 下 KL 0.0057，
   与 cnn_m（2.0M，KL 0.0055）持平；炸掉的只有 HRF（23.2M，**45 LayerNorm / 18 注意力块**，
   残差深度约 handset 两倍）→ **深残差栈深度**而非参数量预测了不稳定。
4. **定量取值**：二阶近似 KL ≈ ½Δθᵀ F Δθ、Δθ ∝ LR ⇒ **KL ∝ LR²**。
   将 0.0202（exp30 后段）压到 cnn/handset 的 ~0.0055 需 LR × √(0.0055/0.0202) ≈ ×0.52；
   取 **6e-5**（×0.6，预期 KL ≈ 0.0073）为略保守值，避免过度压制学习速度。

## Method
`--arch hrf_xl_v4 --lr 6e-5 --warmup_updates 150 --entropy_coef 0.03
 --entropy_schedule 0:0.03,600000:0.01`（其余与 exp30 逐项一致），
加 `--bf16_infer --amp_update`（已验证 1.63–1.8× 提速且数值等价，不改变优化语义）。1.0M 局。

## Success Criteria
1. **优化健康（主判据，单变量归因的直接读数）**：后段 approx_kl 落入 **0.005–0.010**；
   ladder 相邻点波动收窄到 **≤±40**（exp30/exp36 为 ±50~±100）。
2. **Elo**：T1 **> 852.1**（exp30 同预算同配置）→ 归因成立，此前 HRF 判定作废。
   - ≥1000 → HRF 重回冠军谱系候选；
   - 仍 ~880 但 KL 已进入健康区间 → **架构上限判定才成立**（此时才允许写"HRF 不行"）。
3. 若 1.0M 处 ladder 末段斜率显著为正 → 判"未收敛"，追加预算续训而非当场结论。
