# exp10_arch_sweep（架构探索）

- **Date**: 2026-08-15  **Status**: done（BC 扫描 + RL 毕业赛均完成，vit 毕业通过）
- **动机**: 用户指示「对模型结构进行进一步探索」。与 exp9 并行（BC 走 GPU，不抢 rollout CPU）。

## 方法
BC 作为搜索介质：共享缓存数据集（3000 教师局 / 18.2 万决策，每状态同存两种编码）、
留出集教师复现率为指标、另测 batch-1 CPU 延迟（卡自对弈吞吐的量）。

## 结果
| 架构 | 参数 | 复现率 | b1 延迟 |
|---|---|---|---|
| **vit_small**（牌即 token Transformer） | **0.82M** | **89.3%** | 3.24ms |
| vit_small_order | 0.82M | 89.1% | 3.34ms |
| cnn_l | 3.94M | 82.0% | 2.42ms |
| cnn_m_order | 1.94M | 81.9% | 1.26ms |
| cnn_m（现役） | 1.94M | 81.4% | 0.64ms |
| cnn_s | 1.04M | 80.4% | 0.59ms |
| vit_tiny | 0.11M | 73.9% | 0.86ms |

1. **结构 >> 容量**：CNN 4× 参数只 +1.6pp；Transformer 少 2.4× 参数 +7.9pp。
   收益来自结构先验：牌即 token、每 token 输出该牌的 8 类动作分（精确对应 (类型,牌) 动作空间）。
2. **牌河顺序平面无增益**（CNN +0.5 / ViT −0.2pp）。测量局限：教师决策不读牌河，
   BC 复现率原理上无法奖励教师不用的特征——**不能据此断言顺序对 RL 无用**。
3. **决胜竞技场（400 副）：vit-BC vs cnn-BC = +270 ± 555（p=0.34），无显著差异。**
   +7.9pp 模仿保真度未兑现为强度——与 exp7（62.8% vs 59.2% 复现率的 DNN/LLM 竞技场打平）同构：
   **对平庸教师的模仿保真度，边际上不换强度**（多学的那 8pp 可能落在无关紧要或教师本就错误的决策上）。

## 毕业判定（已完成，2026-08-15/16）
vit 的真正考验不在 BC 而在 RL：结构先验是否带来更快/更高的自对弈学习曲线。
计划：exp9 完成释放 CPU 后，用 exp9 胜出配方（如 ppo_epochs=1）从零训 vit_small 240k 局，
与 cnn 的既有 240k 标度点同尺同比。延迟代价（3.24ms vs 0.64ms → 吞吐约 1/2-1/3）计入判定。

**RL run**：`dnn_vit_rl_20260815r4`（GCS；r2/r3 因 spot 抢占/迁移作废从零重跑），
g2 L4 云机，exp9 胜出配方（ppo_epochs=1，其余同 exp8/9 标准超参），240k 局跑满，
自对弈 win_rate 终点 0.604（cnn-PPO44 同里程碑 0.47）。checkpoint 80k/240k 已缓存
`experiments/_cloud_ckpts/dnn_vit_rl_r4/`。

**毕业竞技场**（2026-08-15 晚由上一会话执行，结果 JSON 存 `experiments/exp10_arena_*.json`；
本记录 2026-08-16 补写）：

| 对局 | 副数 | 配对分差 | 判定 |

## 结论
1. **vit 毕业通过，且是迄今最大的单点竞技场效应**（+1633，此前最大为 exp9 的 +1802 同量级；
   对比 BC 决胜的 +270 null）——「结构先验在 BC 保真度上不兑现强度，但在 RL 下兑现」，
   修正了 BC 阶段「保真度不换强度」的悲观读数：搜索介质（BC）与最终价值（RL）解耦。
2. 诚实声明（非单变量）：vit 用 exp9 配方（reuse11）从零训练，cnn-240k 点是 reuse44 配方的
   240k checkpoint（exp9 起点，reuse44 在 ≤240k 段是当时冠军配方）；另 vit 参数量 0.82M vs
   cnn 1.94M（少 2.4×）。混杂方向总体不利于把 +1633 全归因给结构，但幅度远超配方效应
   （exp9 配方效应在 600k 才显现，240k 处两配方同点）。
3. 延迟代价实测可接受：云机 240k 局在半天内跑完（吞吐足够）。
