## Purpose & Hypothesis
雀魂实战（`majsoul_exp113C_20261025_000702`，第 1 局）暴露的两个症状都发生在**小 EV 差的平手局面**：
① 牌效：向听最优 90% 但受入最优仅 56%，系统性留字牌单张弃数牌，近似局面策略常 0.4/0.5 对半；
② 防守：有押/退分化（3 向听弃和、1 向听推），但**同向听同受入下有现物也不选**（#90、#115 现物 p=0.0）。

两者共同解释：PPO 用单局回报 + GAE 做优势，受入差几张 / 安牌 vs 非安牌这种量级的 EV 差被优势噪声淹没，策略头在平手局面没有被任何信号推开。
候选杠杆 = 换**改进算子**（AlphaZero 式：用搜索出目标再蒸馏回策略，纯血，不换目标/规模/先验）。最便宜的搜索 = 价值头一步前瞻。

**本探针回答的前置问题**：现有（部分信息）价值头在这些平手局面上**有没有分辨力**。
- H1：一步前瞻的价值排序在平手局面上比策略更接近受入最优/安牌 → 搜索算子有信号 → 下一步蒸馏训练。
- H0：价值排序不比策略好 → 价值头本身是天花板 → 下一步不是放弃，而是训练 **oracle 评论家**
  （全信息四座位联合价值，COMA 式 centralized critic + counterfactual baseline；用户 15:05 提议）后重做同一探针。

## Method
对每个"轮到我切牌"的决策状态 s，对每个合法切牌 d 计算：
- **V0(d)** = V(s 切 d 之后，他家响应前)：克隆 ShadowTable/PyMahjongTable，调用 `dahai(me, d)`，`forward_with_value` 读 V。
- **V1(d)** = E_draw[V(s 切 d、他家全过、我摸 t)]：对每种未见牌型 t（4 − 可见张数 > 0），在 V0 的克隆上 `tsumo(me, t)` 读 V，按未见张数加权。
  （他家全过 = 确定化的最简版本；他家响应的风险由 V0 这一层承担，V 已在自对弈中学到切牌后被荣和的期望。）
- **设计修正（15:10，写脚本时发现）**：① V0 是**分布外**状态——训练中我们从不在自己切牌后的响应窗口被问，评论家没见过这种状态，只作诊断；
  ② V1 对切牌 d 自身的放铳风险**结构性失明**：被荣和的轨迹在那一步就终止了，"切了危险牌还活着"的状态在训练数据里都是幸存者。
  所以安牌分层不能用 V1 判，必须包含他家响应那一步 →
- **Vcf(d)**（仅自对弈 B 组可算）：在**真实全信息牌桌**的克隆上强制切 d，他家用同一策略响应（荣和 → 精确终局奖励），
  推进到我下一次切牌决策，再在那里取摸牌期望。这是"确定化的一步搜索目标"，也是 exp72 反事实的一步版本（exp72 rollout 到局末、单样本）。
  A 组（雀魂，他家手牌未知）只能报 V1 → 只用于牌效分层。
- 对照排序：**牌效**用 `TileEfficiency.evaluate_discards_ranked`（先向听、再受入，受入按可见牌扣减）；**安牌**用现物（对所有立直/≥2 副露家都在其河里）。
- 比较排序器的 argmax：策略 π（T=0）、V1、Vcf（B 组）、V0（诊断）。
  **判决用的"搜索算子"读数 = Vcf**（牌效 + 安牌两层都看）；V1 只补牌效层的 A 组证据。

两组决策来源：
- **A. 雀魂实战**：回放 `majsoul_exp113C_20261025_000702/mjai_session.jsonl` 两局的事件流，经 `MjaiDnnBot` 重建每个切牌决策的 ShadowTable（他家手牌未知，编码器不读）。
- **B. 自对弈批**：exp113 C 四份同桌、T=0、随机场况，`play_game_gen` 驾驭；每局每席的切牌决策按 p 抽样做同样计算。
  自对弈牌桌有真实隐藏信息，但编码器只读本席视角，V0/V1 与 A 组同义，可合并统计。

局面分层（预先定义）：
- **平手牌效局面**：无立直在场，策略 top-2 概率都 ≥ 0.30。
- **安牌平手局面**：有立直或 ≥2 副露家在场，存在一张现物候选与策略所选"同向听且受入差 ≤ 2"。
- 其余（策略已很确定的局面）只报总体一致率作背景。

## Success Criteria（发射前定）
设平手牌效局面 n_eff、安牌平手局面 n_def（目标 n_eff ≥ 300、n_def ≥ 60，不足则只报方向）。
- **H1 成立（有信号）**：平手牌效局面上 Vcf-argmax（A 组用 V1）的"向听+受入最优"命中率 ≥ π 命中率 + 15 pp（且 ≥ 50%）；
  **或** 安牌平手局面上 Vcf 把现物排第一的比例 ≥ π 的比例 + 20 pp。
- **H0（价值头是天花板）**：两项都在 π ±5 pp 内。
- 中间地带：报数字，不下判决，倾向按 H0 处理（保守）。
- 附加诊断（不计入判决）：V1 与受入计算器的 Spearman 相关；V0−V1 在现物/非现物上的差（放铳风险是否体现在 V0 层）。
