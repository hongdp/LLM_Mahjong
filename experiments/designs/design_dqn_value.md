# 价值方法线 v1：DQN on 人类先验（exp59 设计，2026-08-31）

## 动机（为什么在 exp55-D 打平之后开这条线）

exp55-D tranche-1 的三条诊断指向同一病灶：**策略梯度读不动排位价值信号**——
explained_var 只有 0.09（价值头解释不了 W 信用回报）、bc_kl 漂移 0.02 但分歧弥散
（120 例逐例复盘 = 价值中性的边界抖动，10 例牌理判读 3:3:4 不分胜负）、风格九项全平。
PG 的信用链是 `优势 = 回报 − 基线`，基线（价值头）学不会时优势就是噪声，策略只能漫步。

价值方法把这条链倒过来：**直接回归 Q(s,a) = 期望回报**，策略 = argmax Q。三个结构性优点
正好打在我们的痛点上：
1. **目标策略即部署形态**：Q-learning 的目标策略是贪心——与 T=0 裁决刻度天然同条件，
   没有 PPO 的「训练 T=1 / 部署 T=0」错位与采样税。
2. **离策略 + 经验回放**：同一批对局可以反复学习（PPO 每批只能 4 passes），
   高方差的排位回报靠回放的重复采样磨平，而不是靠加大批量。
3. **对手冻结 = 环境平稳**：league 三席全 T=0 冻结锚时，单学习席的 MDP 是平稳的，
   这是 Q-learning 收敛前提里最难得的一条，我们的四席桌免费给了。

## v1 设计决策（最小增量，全部复用现有基建）

| 决策 | 选择 | 理由 |
|---|---|---|
| 刻度 | **先单局，后半庄** | 单局有 bc49/exp46I 的成熟基线与便宜评测；机器验证过了再上排位（W 信用接 Q 目标是 v2） |
| 桌型 | 学习席 ×1 + league 冻结 T=0 ×3（bc49 entry0 + exp46I） | 环境平稳；league_frac=1 复用 exp22 机制 |
| 网络 | bc49 trunk 热启动，**policy 头直接当 Q 头**（权重照抄） | logits 的 argmax = bc49 贪心 ⇒ 行为从 bc49 水平起步，不经历随机期；TD 会把量纲拉向回报尺度 |
| 行为策略 | Boltzmann(Q, T=1)（复用 net.act 的温度采样，rollout 栈零改动） | ε-greedy 需要改 worker；Boltzmann 初期 ≈ bc49 采样，随 Q 锐化自然退火 |
| 损失 | **Double DQN** + Huber，目标网每 `target_every` 次更新硬拷贝 | 过估计是 DQN 头号病，Double 是标配解 |
| 回放 | 环形缓冲 100 万 transition（planes fp16 ≈ 4KB/步 → ~4GB RAM），均匀采样 | v1 不上优先回放，少一个调参维度 |
| 折扣 | γ=0.995（沿用 PPO 默认；单局内步数 ~110） | 与既有回报口径可比 |
| 奖励 | 现有 registry 奖励原样（终局点差 + 顺位奖），**scale 0.05** | 把回报压到 ±3 量级，贴近 logits 初始尺度，缓解热启动量纲错位 |
| 合法性 | mask 外 Q = −inf（目标 max 同样只在 s' 的合法集上取） | 与现有 mask 机制同构 |

## 已知风险与对策

- **热启动量纲错位**：抄来的"Q"是 log-policy 尺度（±5），真回报（scaled）±3——接近，
  但语义不同；前几千次更新 TD 误差大属预期，看趋势不看绝对值。若行为在早期崩坏
  （贪心评测掉 >100 Elo），退路 = 冻结行为为 bc49 采样先做纯离策略评估 5 万局再放开。
- **死亡三角**（函数逼近 × 自举 × 离策略）：目标网 + Double + 大回放是标准三件套；
  监控 Q 均值 vs 实际回报均值的比率（>2 即过估计警报）。
- **回放里的旧策略数据**在环境平稳下无偏（off-policy 合法），但行为分布漂移后
  状态覆盖会偏——v1 接受，监控 TD 误差分布。

## 判据（预注册在 exp59 EXPERIMENT.md）

冒烟（本地）：TD loss 下降且不振荡发散；Q 均值/回报均值比率进入 [0.5, 2]；
贪心行为不崩（对 bc49 快评 ≥0.45）。
正式（云）：200k 局后贪心 vs bc49 单局 n=2000 ≥ 0.48（机器有效判据——PG 同预算打平 0.50，
DQN v1 只要证明「价值方法能在这个引擎上学」）；风格/Q 校准曲线入 TB。
**北极星判据（v2 再谈）**：半庄 + W 信用目标下超过 exp55-D 的打平线。
