# 纯血线：Q learning、反事实评估与回放数据选择（分析记录，2026-09-06）

> 与用户的四轮讨论整理。背景：exp68/69 判定从零 RL 的防守缺失不是感知问题，单局点差设定下"都不防"是均衡；
> exp70（半庄顺位奖励）在跑；exp71（从零 Double DQN 判决实验）在跑。本文记录方法论结论，供 exp71 判决后的下一轮取用。

## 1. 单局目标下的最优防守量（修正 2026-09-06 早先的说法）
- 反例：exp46 C 系列从 bc49 起步、对手就是 bc49，RL 后 defense_iq 0.184 → 0.072–0.188，头对头不掉分；exp63：exp46I 点差打平 bc49 但四位率 27.4% vs 24.5%。
- 结论：**单局终局点差目标下，即使对手是 bc49，最优防守量也低于人类。** 人类/bc49 的防守是半庄顺位目标的产物。
  换强对手不会让防守在单局训练里涌现；要改的是目标（exp70 的直接理由）。
- 推论：纯血线对 bc49 的单局差距（≈3,000 分/席/局）主要是牌效/速度（和牌率 11% vs 22.5%），放铳只解释 600–700 分；这是样本效率问题
  （人类示范每局信息量 ≈ 自对弈千倍）。exp70 的预期因此分两半：防守涌现 + 半庄刻度为正；单局刻度对 bc49 未必缩小。

## 2. Q learning 对从零训练的价值（分解）
| 瓶颈 | Q learning 是否命中 | 说明 |
|---|---|---|
| 归因信噪比（σ≈5,000 的 MC 回报 vs 几百分的弃张价值差） | **命中** | 一步/n 步自举把目标方差降到一步内噪声；代价是 V 不准时系统性低估防守 |
| 样本效率（从零配方 ppo_epochs=1，每样本一次） | **命中** | 回放池复用；exp60 演员-学习者基建为此铺路 |
| 均衡/目标（单局点差下不防守） | 不命中 | 换估计器不挪均衡点 |
- 反面证据：exp59 从 bc49 热启动的**去锚**纯 TD 掉到 0.21 ≈ 纯血水平 → 5–20 万局尺度 TD 不含排序信息；从零+ε 探索会拆手牌（回放里堆垃圾轨迹）。
  文献无从零 Q learning 达人类高段的先例（Suphx 策略梯度+先知引导；Mortal 人类 BC 起步+Q 式目标+GRP）。
- 推荐形态：保留 PPO 策略头与熵探索，给 critic 加回放 + n 步目标（IMPALA/V-trace 一类）或离散 SAC；纯 DQN 从零只做判决实验（exp71）。
- **从零 off-policy Q 从未做过**（exp59/60 均热启动）；exp60_r2_store（12.4M 步）是 bc49 谱系演员产的，用于从零训练破纯度且有分布偏移问题。

## 3. Q learning 不自带反事实评估；模拟器 + 先知信息才是我们的独有资源
- Q 的"反事实"只有一步（目标里的 max_a' Q(s',a')）；Q(s,a') 对未执行的 a' 仍靠泛化，策略从不弃安全牌则"弃安全牌"的 Q 是外推。
- 训练时我们知道真牌山与四家暗手 → **决策级反事实 rollout**：克隆牌桌，候选动作各打到局末（牌山不变、当前策略续打），配对差 ≈ Q^π(s,a)−V^π(s) 的低噪声估计。
  与评测的配对牌山、exp70 的 dup_k=8 组基线同一原理，下放到决策层。先知信息只进优势估计不进策略输入（纯度同 exp67）。基础设施：`scripts/rollout_label.py`（克隆+续打）已有。
- 三档实现（便宜→贵）：①全动作优势基线（COMA/MAC，Q 仍是学的）；②**决策级反事实 rollout 优势**（抽样：立直后每手 + 5% 随机点，K=4 候选 + 最安全牌，
  ≈+20–30% 算力，替换该决策的 GAE）；③后悔式更新（NeuRD/RPG）。建议 exp70 判决后实现②，约一天。
- 限制：深度一步（续打由当前策略完成，防守序列靠多轮改进展开）；不改目标（单局点差下反事实会诚实算出弃张不划算）。与 exp70 是配合关系。
- 人类复盘类比：成立。只复盘关键手 = 抽样；对比而非绝对评价 = 配对差；一局一个后验样本 = 结果论风险，SGD 小学习率聚合数千次 = 结果论的正确版本。
  人类复盘还会"对照强者"（Mortal/NAGA 看牌谱），纯血线放弃这一来源，故对目标设定极其敏感。

## 4. 回放数据选择：按"牌局水平"清洗（用户提议，安全）
- 迭代序号 ≠ 水平（exp60 r2：gen_0010 0.4859 < gen_0002 0.4993）。用**实测评分**：每代产出时对固定纯血锚（P3，T=0，1,000 对≈2 min）测 share，写入分片元数据。
  镜像自对弈一局水平 = 该代评分；混桌取四席最小值（对手水平决定学习者看到的状态分布）。
- 用法：硬门槛（下限随最强代上抬）+ 软加权（评分 softmax 采样）；FIFO 滑窗是其退化版本，仅训练单调时等价。
- 实现全在 store 模式数据层：`value_actor.py` 写评分、`replay_store.StoreReader` 过滤/加权、训练器两个旗标；约半天。exp71 判决为正再做，为负则问题不在数据纯度。
- 与人类先验线 `--seat_min_rate`（只用高 R 席位）同一原则。

## 5. 人工提高回放中小概率事件的比例：偏差分类
| 提高的是 | 是否有偏 | 说明 |
|---|---|---|
| **罕见状态**（立直后决策、终盘、字牌多起手） | 基本无偏 | 逐条 transition 的目标不变，只改回归权重（容量倾斜）；函数逼近下需 IS 权重修正，温和 |
| **罕见结果**（同一 (s,a) 下放铳/一发/海底） | **有偏** | Q 是环境转移分布下的期望，多抽"放铳了"→ Q 系统性悲观；消偏要乘 p_env/p_sample，方差回到原点 |
- 麻将里几乎所有罕见事件是第二种 ⇒ **TD 误差优先回放不能用**（强随机环境里高 TD 误差 = 运气极端，按误差优先 = 按结果优先）。要优先只按状态特征，并加 IS 修正。
- 想让小概率大损失权重高于其概率 → 改目标（风险敏感/CVaR），不是偏数据；半庄 uma 本身就是这样的风险变换（exp70）。
  多抽放铳 transition 能"制造"防守，但那是错误价值函数换来的行为，对手一强就露馅。
- 无偏降罕见结果方差的正路：训练时知道暗手，对隐藏状态后验求期望（exp66 确定化思路 / 先知 critic）。

## 6. 课程示例：国士无双（按起手筛/多发字牌多的起手）——无偏，四条边界
1. 只按**起手**筛，不按过程/结果筛（"起手字牌≥7"可；"字牌多且进张顺"不可；"最终成国士"更不可）。
2. Q 定义在**观测**上：筛选条件必须是学习者可见信息。按对手起手筛会改学习者信息集内的后验 → 有偏。
   四席镜像（exp71 四席 episode 全进回放）下，按东家起手保留整局：东家无偏，另三席被"对面攥字牌"这一隐藏条件筛过 → 只保留该席 episode，其余按原采样率。
3. 状态覆盖 ≠ 动作覆盖：需要同一起手上"做国士"与"拆掉"两分支都有数据；多保留状态不解决分支稀缺，靠探索或决策级反事实 rollout。
4. 权重不极端：万分之几抬到百分之几可，抬到一半以上是容量零和的代价。
- 这是纯血线里少数完全干净的先验注入方式：不带人类策略信息，只指定"哪类局面多练"。
