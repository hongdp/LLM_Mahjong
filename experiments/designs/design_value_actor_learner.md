# 价值方法线 v2：演员/学习者解耦 + 历史 ckpt 联赛 + 持久对局库（exp60 设计，2026-09-02，用户提出）

## 一句话
演员编排器不停用"最新策略 + 池子里轮换的历史/锚点模型"凑桌打牌，**四席全部落盘**；学习者不停从对局库采样训练，
一个 iteration 训到收敛就存 ckpt 进池子；演员随时优先用最新 ckpt（每桌至少一席），如此迭代。
= Ape-X 式异步演员/学习者（离策略天然允许演员权重陈旧）+ AlphaStar 式历史联赛 + 离线数据集。

## 为什么现在做（exp59 v1.x 的结论）
- 无探索的离策略 Q 只能复现先验（0.4985/0.4901/0.493 全在噪声带内）；纯 TD 在 5 万局尺度重建不了排序，
  锚是唯一防线（无锚 0.21）。**病根 = 覆盖 + 样本效率**，不是优化器，也不是可训参数量（头-only≈全微调）。
- 串行"采集→更新"让 GPU/CPU 轮流闲置，replay_ratio 被采集速度绑死；对局用完即弃（55 万局一局没留）。
- 价值方法**独有**的红利：演员权重旧几个版本无害（PPO 做不到），推理服务器常驻/权重滞后都合法。

## 组件（全部走文件系统通信，pod/工作站通用）

```
pool_dir/                      # 模型池：固定锚点 + 历代晋级 ckpt
  anchors.json                 #   [{name, path}] 固定成员（bc49、exp46I）
  gen_0001.pt ...              #   学习者晋级的代际 ckpt（最新 = 最大编号）
store_dir/                     # 对局库：只追加的分片
  shard_<ts>_<n>.npz           #   每片 ~512 局四席全收：planes uint8(×20) + mask packbits
                               #   + scalars fp16 + actions/rewards/returns + 每席 model 标签
  shard_<ts>_<n>.json          #   元数据：局数、步数、演员用的 gen、池子构成、单点偏离参数
```

- **演员** `scripts/value_actor.py`：循环 {读池子 → 最新 gen 当学习席（每桌 1 席，随机落座；`league_plan` 现有逻辑）
  → 其余三席逐席从 池子(锚点 + 最近 K 代) 均匀抽 → 全 T=0 + 学习席单点偏离 → `collect_parallel(all_seats)` → 写分片}。
  读到 `STOP` 文件退出。多台演员可并行（分片名带主机/进程号）。
- **学习者** `scripts/train_dnn_dqn.py --store_dir`：循环 {把最新分片解码进 RAM 环（1–2M transition，
  近期优先；老分片按比例保留）→ 固定 N 次更新 → 记 TB}；每 `promote_every` 次更新做**晋级评测**：
  贪心 vs 当前最新 gen（复式对 n=1000，T=0）——**不劣于（≥0.50−1σ）即晋级**为 gen+1 写入池子；
  劣于则继续训（不晋级），连续 M 次不晋级 → 报警（学习停滞）。
- **回放**：环里近期数据为主（最新分片全收），老分片随机抽 20% 保留分布广度；DQfD 锚永远是 bc49 贪心。

## 数据格式（实测决定）
v3r 平面 21 个离散值（k/20），98.6% 为 0/1 → `uint8(planes×20)` + `np.savez_compressed`：**58 字节/步**
（fp16 3808）。100 万局 × 4 席 × ~28 步 ≈ 1.1 亿步 ≈ 6.5GB planes + mask/标量 ≈ **~10GB**。

## 判据（预注册见 exp60 EXPERIMENT.md）
- 基建：演员吞吐 ≥ 串行 rollout 的 90%；学习者更新吞吐不受演员影响；分片读写往返逐位一致。
- 学习：**代际曲线**——gen_k 贪心 vs bc49（n=4000 单局，T=0）随 k 单调不降，且任一 gen ≥ 0.52（+2.5σ）
  即"价值方法在本引擎上产生了先验之外的增益"成立；三代不涨 → 停，写诊断。
- 每代晋级评测本身就是训练中的强度曲线（对最新 gen，不是对 bc49）——两条线都进 TB。

## 不做的事（v2 范围）
优先回放、分布式多机演员、常驻推理服务器热更新（先用每分片重建，够用）、半庄/W 信用目标（v3）。
