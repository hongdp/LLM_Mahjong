# 纯血线 $200 计划：从零 RL 达到 bc49 / Mortal 水平（用户目标，2026-09-06 立项）

## 0. 目标与判定
- **目标**（用户原话）：用 RunPod 新充的 $200 实现一个从零 RL 训练的模型，达到 Mortal / bc 的水平。
- **纯度约束**：零人类牌谱、零外部模型（含 bc49/Mortal）作为训练信号；允许模拟器先知信息只进优势/critic 估计（exp67/70 口径）；允许按学习者可见起手的课程。
- **达成判定**（终审口径，CLAUDE.md 评测协议）：候选 T=0 对 bc49 **单局配对牌山 share ≥ 0.50**（两段 ≥20k 对）**且半庄头对头 ≥ 0.50**（n ≥ 1,200 场）；
  梯子 Elo 进入 bc49 ±15（当前 bc49 1189.0、Mortal 1199.6）。对 Mortal 用半庄 n ≥ 1,200 场读数。
- **里程碑**：M1 对 bc49 单局 ≥ 0.40；M2 ≥ 0.45；M3 = 达成。当前纯血最强 0.32–0.33（P3/G3；exp27A 0.203），Elo ≈1060，差 ≈125–135 Elo。
- **停止规则**：达成 → 加冕流程；预算耗尽 → 明确报告最终刻度与缩放曲线并停。任何一轮开跑前预注册 + 报预算上限（CLAUDE.md）。

## 2. 阶段 B：杠杆判决（按 exp70/71 结果排序，逐个预注册为 exp72+）
判据统一：候选 vs 同预算基线（P3 或 exp70 胜者）T=0 两段 ≥20k 对，**share ≥ 0.53**（z≥8）才算杠杆成立；0.50–0.53 记"中性"，不入组合。
1. **决策级反事实 rollout 优势**（设计见 `design_offpolicy_data_and_counterfactual.md` §3 第②档）：立直后每手 + 5% 随机决策点，K=4 候选 + 最安全牌，
   真牌山续打配对差替换 GAE；先知只进优势。预计 +20–30% 算力。目标：防守信号可见化。
2. **回放 + n 步 critic / 离散 SAC**（若 exp71 ≥0.45 才立项）：保留 PPO 策略头与熵探索，critic 用回放与 n 步自举。
3. **对手压力**：先知可见的自我副本作训练对手（exploiter），检验"对手强则防守值钱"是否在半庄目标下成立。
4. **课程**：按学习者可见起手的分布重加权（无偏），配合 1。
5. exp70 若判正：后续全部在半庄顺位目标上做；若判负：单局目标 + 1/3 为主，并记录"防守不可从零涌现"的边界。

## 3. 阶段 C：规模
- 组合成立的杠杆，配方钉死，预算 10× 单轮（≈10M 局）；吞吐不够时用 exp60 演员-学习者拆分（1 学习者 : 2–3 GPU 演员 pod）。
- 中读：2.5M / 5M 局 ckpt 对 bc49 两段配对；**早停**：若 (0.33→中读) 的对数线性外推到 10M 局仍 < 0.40，停下重分配到阶段 B 新杠杆。
- 交付物：纯血线 share-vs-局数 缩放曲线（与 BC 数据缩放曲线 1.41 pp/decade 并列写进 FINDINGS）。

## 4. 可行性声明（诚实预估，立项时写明）
- 有利：目标改变（exp70）与反事实优势是尚未测过的两个最大杠杆；样本效率线（回放/演员-学习者）基建已就位；$200 ≈ 180 L40S 小时 ≈ 单卡 3,000 万局量级。
- 不利：人类示范每局信息量 ≈ 自对弈千倍（FINDINGS 08-27）；文献无从零 RL 达人类高段先例（Suphx/Mortal/NAGA 均依赖人类数据）；
  纯血线 5 条路线（exp61–69）已清掉感知/对称/先知等杠杆，剩余差距被诊断为**样本效率 + 目标**。
- 预估：$200 内达成 bc49 平手的概率约 10–20%；达到 M1（0.40）约 50%。无论结果，本计划交付"从零 RL 在此预算下的缩放曲线与各杠杆的量化贡献"。

## 5. 阶段结论（2026-09-08，累计花费 ≈$38.8 / $200）
- 五个杠杆：感知 ✗、目标 ✗、估计器 ✗、归因 中性、稠密效率 固定 ✗ / 退火 微正（+1.5 pp）。规模：**对数线性 ≈+1.5–2 pp/倍增**（1M→4M：vs P3 0.523→0.558，vs bc49 0.33→0.356）。
- 纯血最强 exp75_X：vs bc49 0.356（M1 0.40 差 4.4 pp），Elo 待梯子补测。
- **$200 内达 bc49/Mortal 不可行**（需 $1.5–6k 的纯规模，或尚不存在的新杠杆）。剩余 ≈$161 的去向待用户决定：
  (a) 延长缩放到 16–32M 局（$50–100，预期 M1 0.39–0.41，交付更长的缩放曲线）；(b) 停止，保留预算；(c) 转人类先验线（bc65 加冕、Mortal 差距 8–20 Elo）。
