## Purpose & Hypothesis
纯血线训练侧与目标侧全部关闭后，剩下唯一有文献大效应的机制是 Suphx 的 run-time policy adaptation（适应版对非适应版 66% 胜率）：开局时按当前手牌采样 K 个隐藏信息样本，自对弈到局末，用这些轨迹对策略副本做几步策略梯度，再用副本打这一局。它和 exp86 的搜索不同：不是在单个决策上比较回滚均值，而是把整局的条件分布信息压进参数。
- **H1**：适应版对未适应版同牌山配对点差 ≥ **+150 分/局**（z≥3，2,000 局），且方向在两组超参下一致 ⇒ 值得做对 bc49 的 20k 对评测（需要 Python 引擎侧的适应包装，另行工程）。
- **H0**：≤ +50 或两组符号不一致 ⇒ 关闭；纯血线推理侧也判决完毕。
- 反解释：适应改变了 23% 局的结果（冒烟），若均值为负说明几步 PG 在 1.8k 样本上主要是噪声注入。

## Method
- 触发：seat 0 第一次切牌决策（`discard_count[0]==0`）；K ∈ {128, 256} 个 `determinize(0, seed)`；首动作按基策略 T=1 采样；四席都用基策略 T=1 自对弈到局末；取 seat 0 轨迹（≈1.8k 样本/局），PPO-clip（0.2）+ 归一化优势（基线 = 均值），Adam lr ∈ {1e-4, 3e-5}，steps ∈ {4, 2}，梯度裁剪 1.0；副本只用于本局 seat 0 的 TURN 决策（副露/荣和判断仍用基策略）。
- 评测：2,000 局，seat 0 适应版 vs 3×M，与 seat 0 基策略同 seed 配对。
- 成本：0.28 s/局适应，$0。
