# exp49（预注册）— 顶部平带归因：超参直测 + 100% 数据仲裁

- **谱系**: 人类先验谱系。用户批准复活 100% 数据点（只跑顶部 3 臂）。

## Purpose & Hypothesis

r300 复评后顶部四臂为 ±11 统计平带（conv×v1r 1145.6 / SEres×v3r×46 1138.1 /
conv×v3r×46 1134.9 / mortal46 1127.9），而精度端容量/结构增益持续存在——增益在强度端蒸发。
三个候选解释按嫌疑排序：① 10% 数据量下容量不咬合；② 精度→Elo 顶部脱钩
（分布/规则错位、误差复利）；③ 训练超参不适应大模型（用户假设：共用 lr 3e-4、无 warmup 无 decay）。

- **H-A（超参）**：SEres×v3r×46 在更小 lr 或 cosine decay 下精度/Elo 显著上移 → ③ 成立；
- **H-B（数据缩放）**：100% 数据（~18.4k 局，9× 样本）下大臂相对 conv×v1r 的差距显著扩大 → ① 成立；
  若全量下平带依旧 → 解释权归 ②，"简单模型即旗舰"结论加固。

## Method

**A 部：lr 直测**（10% 数据、同协议，SEres×v3r×46 两个新格；基线=已有 lr 3e-4 acc 0.7553）：
- A1 `--lr 1e-4`；A2 `--lr 3e-4 --lr_schedule cosine`（新增调度器，per-epoch 余弦至 0.1×）。
- 择优规则（自动）：holdout acc 最高者的配置进入 B 部 SEres 臂；
  若 cosine 胜 → B 部全臂启用 cosine（调度是尺寸无关的普适改进）；
  若两格均不超基线 +0.3pp → ③ 证伪（记录），B 部沿用 3e-4/const。

**B 部：100% 数据三臂**（train=全部非留出 ~18.4k 局、holdout 1000 局、max_epochs 30、patience 3）：
`convformer_m_r`（2M 现旗舰）/ `convformer_m_v3r_m46`（2M）/ `mortal_bb_xl_v3r_m46`（11.1M，用 A 部胜出配置）。
评估：Elo deals=300 新种子 45400001（直接 r300 精度口径）+ defense_iq（seed0 45500001）。

## Success Criteria

1. **H-B 主判据**：100% 点上任一大/结构臂对 conv×v1r@100% 的 Elo 差 ≥ +20（≈2σ@se7.6）
   → 容量随数据兑现，旗舰易主，北极星路线改为"全量数据 + 该臂"；
2. 平带依旧（所有两两差 <20）→ 旗舰定格 conv×v1r，结论"10%→100% 数据缩放在强度端饱和"入账，
   下一杠杆转向 exp46（RL-on-prior）与外部读数（雀魂 maka）；
3. H-A 独立报告：lr/调度对大模型的精度效应量，无论正负记入 SKILLS（超参-尺寸交互的直测数据点）；
4. 诚实条款：10% 臂与 100% 臂的 Elo 比较跨批次同锚同引擎（mismatch 打标一致），可直接比。
