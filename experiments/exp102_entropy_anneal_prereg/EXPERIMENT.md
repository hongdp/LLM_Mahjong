# exp102 平台期熵系数收尾退火：α=0.03 是不是纯血线平台的原因（用户 2026-09-28 批准，上限 $8）

- **Date**: 2026-09-28  **Status**: prereg → launching
- **Git**: 代码与 exp101 p2 完全相同（repo101.tar，a89161f + arch_zoo）；只改 `--entropy_schedule` 与 seed
- **Env**: 纯血线；Rust 引擎镜像自对弈；从 exp101 cnn_l p2 的 **192M ckpt**（`exp101_L_p2/games_192000000.pt`，20k 对 vs bc49 0.4541）`--resume`

## Purpose & Hypothesis
exp101 三点 112/160/192M 给出 cnn_l 平台 ≈0.455 = Q1x 平台，训练日志 pg≈0、KL≈0.001、H≈1.0 nat（bc49 0.49）。平台是熵梯度与策略梯度**互相抵消**的静止点，
不是策略梯度为零。用户质疑：α=0.03 本身会不会是停滞原因？证据链上的空洞：所有降熵测试（exp78-C2 α→0.003、exp80-C2 熵地板下调）都在 α=0.01/H≈0.5 谱系上做，
**α=0.03/H≈1.0 的当前谱系从未做过收尾退火**；exp98 的有效样本只有常规 5%，不算判决。理论上软最优策略的损失上界 α·ΣH ≈ 0.03×20×1.0 ≈ 600 点/局，量级不可忽略。
- **H1（α 是原因）**：把 α 退到 0.003 后策略沿被压住的方向尖锐化，H → ≈0.3–0.5，T=0 vs bc49 相对同局数对照 **≥ +0.5 pp**。
- **H0（α 是症状）**：H 降但强度不动（复现 exp80-C2 形态），|Δ| < 0.5 pp。

## Method
- 单变量：与 p2 完全相同的 COMMON（cnn_l_v3r、lr 3e-5、γ 0.995、λ 0.95、batch 4096、dup_k 8、games_per_iter 2048、target_kl 0.03、adv_clamp 5、ppo_epochs 1、`--shaping --shaping_schedule 0:1.0,400000:0.0`（早已归零）、`--amp_update`），
  只把 `--entropy_schedule` 从 `0:0.03` 改为阶梯退火 **`0:0.03,194000000:0.02,196000000:0.01,198000000:0.006,200000000:0.003`**（训练器的 schedule 是计数器阶梯函数），seed 1021。
- 总量：192M → **224M**（32M 局）；里程碑 200/208/216/224M。对照 = **p2 本身**（同谱系、同局数、α 不变），224M 处两臂各 20k 对 vs bc49（本机 $0）。
- 机器：Secure RTX 4090（$0.74/h，exp101 实测 1,040 局/s ⇒ 32M ≈ 8.5 h ≈ $6.3）；无货则 Secure 3090（$0.50/h，≈550 局/s ⇒ ≈16 h ≈ $8）。**上限 $8**（含坏宿主损耗），不与 p2 共机（rollout CPU 受限）。
- 监控：心跳（18 h 窗）、拉取+GCS（`gs://llm-mahjong-experiments/exp102_A`）+TB 镜像（`exp102_A_LIVE`）、在轨每 8M（vs M/bc49/Q1x + 弃和探针 + 牌类探针）。
- 预注册延伸：若 H1 成立，追加剂量臂 α→0.0003（另 $6）与 Q1x 谱系复现；若 H0，α 作为平台原因关闭，exp101 p2 按原判据跑完。

## Success Criteria（预注册）
1. **健康**：退火后 H 不低于 0.15 nat（塌缩线，exp8 在 0.44 崩过但那是早期；此处策略已成熟）、KL 常态（≤0.03/更新）；破线 ⇒ 停并记录。
2. **判决（224M，20k 对口径）**：A − p2@224M **≥ +0.5 pp（≈1.4σ，方向 + 幅度）且 A ≥ 0.462** ⇒ H1，α 是平台原因之一，追加剂量臂；
   |Δ| < 0.5 pp ⇒ H0；≤ −0.5 pp ⇒ 退火有害（软最优的探索价值在平台期仍在起作用）。
3. 在轨读数（n=500/1000）只用于健康与方向；判决只认 20k 对。
4. 额外记录：退火前后 H、切牌有效选项数（同口径熵探针）、弃和/放铳率是否变化——H1 下期待防守行为随尖锐化改变。
