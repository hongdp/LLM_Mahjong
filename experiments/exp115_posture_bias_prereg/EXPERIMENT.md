# exp115 — 持续姿态偏置探针：受威胁时整局持续的"现物倾向"能否在纯血人口里赚分（$0，本机）

- **Env**: 纯血线诊断；冻结策略 = exp113 C 384M（cnn_l_v3r，`experiments/exp113_C/games_final.pt`）；Rust 引擎；本机 4080；零云费用

## Purpose & Hypothesis
exp114（逐帧对照）显示 bc49 的优势主要来自"对手立直、自己未听牌时打现物"，且需要连续多巡执行（同牌山接管：单步 +150 ± 76、持续 +309 ± 85）。逐步独立的熵探索很难产生这种连续行为。
本探针测：**给纯血策略加一个整局持续的 logit 偏置（只作用于受威胁时的现物弃牌槽位），在纯血自己的人口里是否净赚**。若赚，说明"时间相关的姿态探索"能找到 bc49 式防守，值得做成训练期算子；若不赚，说明这种防守要配合 bc49 的整体手型管理才值钱，单靠倾向偏置不行。
- **H1**：存在某个偏置配置使 0 号座位每局得分显著为正（≥ +10 分/局，> 2 SE），且最优强度不是边界值。
- **H0**：所有配置 ≤ 0 或不显著。

## Method
- 同一牌山打两遍（同一批次内槽位 2i / 2i+1 同种子），全 T=0、确定性。偶数槽 = 原策略；奇数槽 = 只有 0 号座位整局加偏置，其余三家不变。Δ = 偏置槽 0 号座位终局点数 − 基线槽 0 号座位终局点数（一墙一个样本，SE 即墙聚类）。
- 偏置：对手有人立直且自己未立直时，给"现物"弃牌槽位（discard / discard0，现物 = 立直者河中牌 + 其立直后他家打出的牌，Rust `safe_info`）的 logit 加 b；按自己向听分三档 f0（听牌）/ f1（一向听）/ f2（两向听以上）。另测鸣牌倾向 c（吃/碰/杠槽位 ±b）。
- 配置：AA（零偏置，必须全部 Δ=0）；f1、f2、f0 各 +1/+2/+4；f12（f1=f2）+2/+4；c −2/+2。每配置 40,000 墙。
- 记录：Δ 均值 ± SE、被偏置改变首选的决策数、偏置槽与基线槽的和牌/放铳率。

## Success Criteria（预注册）
1. AA 全部 Δ = 0（确定性配对成立），否则先修。
2. 第一阶段（纯血人口）：最优配置 Δ ≥ +10 分/局且 > 2 SE ⇒ 进入第二阶段；否则 H0，记录哪档最接近、为什么。
3. 第二阶段（另行记录）：最优配置用 Python 引擎对 bc49 做 T=0 配对（10k 墙 × 2 段，偏置 RL vs 原 RL），≥ +0.5 pp ⇒ 提案做成训练期"持续姿态探索"算子。

## Conclusion
- **第一阶段 H1 成立**：纯血策略在受威胁的远手局面系统性地防守不足；整局持续的现物倾向在它自己的人口里每局多赚 ≈39 分。
- **第二阶段未过预注册门槛**：对 bc49 +0.39 ± 0.18 pp（2.2σ）< +0.5 pp。但效果真实且两段一致，换算成点数 +128/墙 ≈ +32 分/局，与纯血人口里的 +38.7 同量级 ⇒ 收益能迁移到 bc49 桌，只是份额（逐墙胜负符号）对它不敏感。偏置版 0.4742 是迄今 20k 对口径下的最高读数，但它带人工先验，不计入纯血榜。
- **纯度**：训练零人类数据；"现物"是振听规则事实；但方向来自与 bc49 的逐帧对照，且是人工设计的先验项 ⇒ 按 exp103 先例不进纯血榜。
- 下一步待用户定：(a) 纯血版通用持续姿态探索算子（多个规则特征同时抽持续偏置，由同牌山配对回报自选方向）；(b) 实用版现物先验 + 可学习强度。
