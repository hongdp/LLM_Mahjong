## Purpose & Hypothesis
exp115 证明纯血策略在受威胁远手局面防守不足：人工指定的"现物"持续偏置在纯血人口里 +38.7 分/局、对 bc49 +0.39 pp。但"现物"是人选的规则特征，方向来自与 bc49 的逐帧对照，不纯。
本实验问：**不告诉它任何规则特征，只用"整局持续的随机扰动 + 同牌山对偶配对回报"，能不能自己找到改进方向？** 扰动空间 = 最后一层策略头 W（374×512）的随机低秩 dW = U Vᵀ（秩 8），整局固定 ⇒ 状态相关、时间持续的"姿态"（logits += (hV)Uᵀ，h 为头部 ReLU 特征）。每墙一个扰动，+dW / −dW 同墙对打（对偶 + 公共随机数），G = Σ Δ_i U_i V_iᵀ 即进化策略方向。
- 这是 PPO 做不到的估计器：PPO 的探索是逐步独立的熵噪声，exp114 显示价值在多巡持续执行；这里每个扰动整局持续，且同墙配对把运气方差去掉。
- **H1**：沿 G 走一步后的策略在纯血人口里显著净赚（≥ +10 分/局，> 2 SE，新鲜牌山复核），说明"持续扰动 + 配对"是可用的纯血改进算子；附带看它是否自己提高了受威胁远手的现物率（是否重新发现 exp115 方向）。
- **H0**：G 的半样本余弦 ≈ 0（无信号），或所有步长 ≤ 0 / 不显著。

## Method
- 冻结 exp113 C 384M。只扰动 0 号座位，其余三家为原策略。全部 T=0 确定性。
- **0a 估计**：σ ∈ {0.1, 0.2}（冒烟标定：4096 墙上分别改变 19% / 32% 的局结果；σ=0.5 改变 51%，太大），秩 8，各 400k 墙（seed0 3,000,000 / 3,500,000），chunk 16384。信号检验 = 前后半样本 G 的余弦（独立噪声下 ≈ 0 ± 0.002，维度 19.1 万）。
- **0b 步长扫描**：W′ = W + α · Ĝ · ‖W‖_F，α ∈ {0.005, 0.01, 0.02, 0.05, 0.1}，新鲜 200k 墙（seed0 4,000,000），0 号座位 W′ vs W 同墙配对；同时记受威胁（有人立直、自己未立直、向听 ≥1、轮到自己切）时选现物的比例。
- **0c 复核**：最优 (σ, α) 在另一组新鲜 200k 墙（seed0 4,500,000）复测（去掉选最优的偏差）。
- **0d 对 bc49**：复核通过的 W′ 存 ckpt，用标准 pairdiff 评测器 T=0 对 bc49 10k 墙 × 2 段（102224000 / 102224500），与原版 C 384M 同墙配对。

## Success Criteria（预注册）
1. 冒烟：α=0 / σ=0 的 Δ 全部 = 0（已通过）。
2. 信号：至少一个 σ 的半样本余弦 > 0.01（≥ 5 倍零假设 SE）。否则 H0（随机持续扰动的配对回报里没有可提取的方向）。
3. 纯血人口：0c 复核 Δ ≥ +10 分/局且 > 2 SE ⇒ H1（纯血改进算子成立）；进入 0d。
4. 对 bc49：0d 配对 ≥ +0.3 pp ⇒ 提案"训练期 ES-姿态步与 PPO 交替"的云实验（另行预注册并报预算）；< +0.3 pp 但 3 成立 ⇒ 记为"只在纯血人口内有效"。
- 纯度：零人类数据、零规则特征；方向只由自对弈同牌山配对回报决定 ⇒ 纯血。
