# exp4_critic 总报告（2026-08-11）

## TL;DR
两条结论方向相反，必须分开读：

1. **critic 本身失败**：价值头的样本外解释方差全程平在 **0.020**（门槛 0.2），优势方差只降 **1%**（门槛 10%）。两条预注册机制判据都不达标。
2. **阶梯竞技场首次测到疑似强度增益**：ep40 对 SFT 锚点 +2950 点（p=0.0027，6 场 Bonferroni 校正后仍显著）——**⚠️ 2026-08-12 更新：该点值未能复现**（exp5 新种子 96 副：+1093，p=0.076）。经复现实验修正后的正确结论是「**平坦的 ~+1000 点增益，各 checkpoint 无实质差异**」，见 docs/report_exp5_confirm_20260812.md。本节以下关于「ep40 峰值」的论述均应按此修正阅读。

## 为什么强度增益几乎肯定不来自 critic
- critic 对优势的实际改动只有 1%（adv_std_ratio 0.99），rl/ref_kl 仅 0.0066——策略更新与 exp2-S 近乎同分布。
- 主判据 critic vs exp2-S 为 null（+634±1231）：两个模型强度不可区分。
- 因此 ep40/ep50 的增益应归因于**「settlement + PPO + ref-KL 这套配置本身」**，exp4 只是第一次用阶梯 checkpoint 去测量它。

**这暴露了 exp2 的一个测量盲区**：exp2-S 只测了 ep50 vs 锚点（−27±1480，null），如果当时也做阶梯，很可能在 ep40 附近同样能看到增益。**「只看终点」会漏掉训练中途的最优点**——这是本轮最有操作价值的方法论收获。

## 一致性核查（做了，没有回避）
传递性：exp4 vs S = +634，S vs 锚 = −27（exp2 实测）⇒ 传递预期 exp4 vs 锚 ≈ +608，实测 +2147，差 +1539 = **1.14σ**（三场合并 SE≈1349）→ 噪声可解释，不构成矛盾，但也说明单场 32 副的分辨率不足以支撑强因果叙事。

另需记住 exp3 的教训：**风格指标可被模板翻 5 倍而质量不变**，所以本轮不用风格解释强度。

## 探针结论：critic 失败的根因不是表征，也不是优化——是这个游戏本身

在**同一批 5918 个状态 / 336 局**（exp4 末 7 个 epoch 的 rollout 日志，中位 18 巡）、同一套**按对局切分**的留出检验（步级切分会因同局共享终局结算而泄漏标签）、alpha 由训练集内 5 折 CV 选定（不在测试集上挑）：

| 探针 | 留出集解释方差 |
|---|---|
| LLM 隐状态（2048 维）→ 回报 | **0.0215** |
| **引擎真值特征（9 维：向听/受入/副露/点数/剩余牌数/立直/供托/手牌数/能量）→ 回报** | **0.0208** |
| LLM 隐状态 → 自家点数（**正对照**，prompt 里明写的量） | **0.4606** |

三行合起来构成一个封闭论证：
1. 正对照 0.46 证明**探针管线有效且隐状态确实编码了 prompt 内容**——不是工具坏了（该对照还用的是回报任务选出的强正则 alpha，属保守下界）。
2. 引擎真值特征 0.021 ≈ LLM 隐状态 0.022，说明**换更好的表征救不了**——诊断从「A1 表征瓶颈」被推翻为 **「A2 回报在该时域内本质不可预测」**。
3. ridge 的 CV 曲线单调偏向最强正则（alpha 1→10⁵，EV 从 −0.80 升到 +0.022），即最优解趋近「预测均值」——无可泛化信号的典型指纹。

**这直接推翻了 critic 路线的立项前提。** 早先「方差分解显示起手仅解释 2%，所以该投资 critic」的推理，遗漏了一个可能：那 98% 里绝大部分不是「中盘状态可解释」，而是**未来牌山与对手行为的不可约随机性**。V(s) 的方差削减上限因此只有 ~2%，与 exp4 实测的 1% 一致。

**附带解释了 PBRS 为何失败**：引擎特征权重里 shanten −0.050、ukeire −0.013 几乎为零，points_k −0.61 才是主导（零和均值回归：手上点数越多，未来点数变动越倾向为负）。**手牌质量几乎不预测终局结算**——而 PBRS 的势函数完全建立在向听/受入之上。exp2 两臂打平至此有了机制层面的解释。

**方差策略必须改向**（不再是 V(s)）：①训练中引入复式牌（common random numbers）直接消掉发牌方差；②vine/反事实的逐动作信用分配，缩短信用链；③单纯加样本量。

## 下一步建议
1. **立即可做（零成本、高价值）**：把阶梯竞技场设为所有 RL run 的标准收尾（每 10 epochs 一档 vs 固定锚点）。exp2 的 null 结论应据此**重新检验**——用它保留的 ep25/26/50 补测。
2. **critic 路线退役**（不是暂缓）：探针证明表征不是瓶颈，v3 也救不了它。同一笔预算应投向「设计上消除随机性」——训练内复式牌是最直接的一项。
3. ~~强度峰值可能在训练中段~~ **已证伪**（exp5）：ep35/40/45 加测后异质性检验 Q=3.58/df=6，各 checkpoint 无实质差异；不存在峰值，也无过训练衰减。
