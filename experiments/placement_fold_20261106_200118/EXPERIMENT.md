## Purpose & Hypothesis
论文 T9 问题：在我们的单局点差目标下，"按顺位弃和"（领先时多防守）有没有价值？
**预注册预期**：单局复式份额变化 **≤ 0**（单局目标下弃和不值，与 09-13 / exp94 反事实一致）；半庄 uma 变化 **> 0**（半庄顺位会奖励保住领先）。两者之差就是顺位依赖弃和的 T9 价值。

## Method
- 基础策略：exp124 A 171.2M 冻结快照（`probes/snap_exp124_A_games_171212800.pt`），T=0。
- 包装（只改本家打牌决策）：触发 = **南场**（round_wind_idx = 1，南 1–4 局）、**领先第二名 ≥ X**（X ∈ {8k, 16k}，按决策时的场上点数）、且**至少一名对手已立直**。
  - **G**：存在对所有立直对手都是现物的牌（= 该对手自己的舍牌，不含其立直后他家通过的牌——偏保守）时，只在现物里按网络 argmax 选；否则不变。
  - **GS**：没有现物时退到筋牌（对所有立直对手：1–3 需 r+3 现物，7–9 需 r−3，4–6 需两侧）；都没有则不变。
  - 触发时不提供立直宣言；和牌 / 鸣牌决策不变。
- 臂：none（未改）、G8、GS8、G16、GS16。
- 结果 1：**单局复式份额**，10,500 去重判决牌山（101112000 起，单局场况中分数与场风随机化，南场 ≈ 50%、分差常见），对 bc49，A = 包装版 vs A = 未改版，同牌山配对差。
- 结果 2：**半庄 uma**，L3 的 1500 场复式半庄（种子 201000000），对 bc49，同场配对差。
- 先报（任何结果之前）：**改动率** = 触发决策中 argmax 被改变的比例，以及每 1000 局（单局）/ 每 1000 场半庄的触发次数。
- 驱动：逐局（batch-1）；发射前校验未改版逐牌山 / 逐场结果与向量评测完全一致。

## Success Criteria
描述性。预注册预期如上；任何方向都报。判读：半庄 Δuma 的 95% CI 排除 0 才算"顺位弃和在半庄有价值"。

## Conclusion
- 单局：符合预注册（≤ 0）——领先 8k 时强制弃和 −0.13～−0.15 pp（点差 −49～−59/牌山，≈2.5σ），16k 时 ≈0（触发少）。
- **半庄：预注册预期（> 0）未兑现**。四个变体全部 ≤ 0（−19～−145 uma/半庄，无一显著为正；GS8 −1.8σ）。在本规则下，"南场领先就按顺位弃和"对 exp124 171M **没有可提取的半庄价值**，反而略亏。
- 解读：171M 本身放铳率已是四方桌最低（L2：0.113），在这些局面里它的原选择大多已兼顾安全；强制只打现物 / 筋会丢掉听牌与好形（改动的 20–35% 决策里大部分是放弃进攻）。即"顺位依赖弃和"作为 T9 的价值，在本模型上**不能用简单规则兑现**。
- **范围戳**：exp124 A 171.2M（单局点差目标训练）、对手 bc49、T=0；触发 = 南场 + 领先第二名 ≥ 8k/16k + 有人立直；现物只算立直者自己的舍牌（偏保守）、筋只做单纯筋；不调整鸣牌 / 立直判断；单种子模型。失效条件：更精细的弃和（含通过牌、壁、点数期望）、名次目标训练的模型、东场 / 西场与小领先。
