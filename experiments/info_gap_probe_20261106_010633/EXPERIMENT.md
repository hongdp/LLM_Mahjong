# 信息差探针：v3r 平面 vs v3r + 完整事件序列（2026-11-06）

## Purpose & Hypothesis
用户 11-06 问"事件序列 transformer 是否信息最完整、交互最自由"，随后批准"做探针"。
在投入 Rust v4 移植 + 事件序列 RL（[architecture_ceiling_20261105.md](../designs/architecture_ceiling_20261105.md) 候选 1）之前，先量化：
**v3r 平面编码相对完整公开事件序列，是否丢了对读牌有用的信息？**
- H1：加入事件 token 后，对手听牌 / 待牌预测显著更准 ⇒ v3r 有信息损失，事件序列架构有抬高平台的信息基础。
- H0：差距可忽略 ⇒ 信息不是瓶颈，事件序列路线预期收益低，资源转向优化信号（exp127 B 臂、优势过滤）。

## Method
- 数据：Tenhou 牌谱经已验证的 MJAI 回放桥（`human_bc_data.game_decisions` 同一路径）逐座位回放；只取本家**打牌决策点**（turn 相位），每点按 0.5 概率抽样。
  输入同时记录 v3r（56×34 平面 + 29 标量，即纯血线主干输入）和 v4 事件缓冲（≤128 事件 × 8 原始字段：牌、种类、相对座位、巡目、新近度、摸切/立直宣言/被鸣/赤/最后打牌/鸣自我）。
  标签由未遮蔽事件流的全信息手牌追踪得到：每个对手（相对座位 1–3）是否形式听牌（shanten=0，含七对/国士，不看役与振听）、待牌 34 维多标签。
- 划分：按局哈希（`is_holdout`，10%），四个座位视角同侧。
- 探针模型（两臂完全相同，只差输入 token）：transformer 编码器 4 层、d=128、4 头；token = 34 个牌种 token（该列 v3r 特征 + 牌种嵌入）+ 1 个标量 token + 3 个对手查询 token；
  - **V 臂**：只用上述 38 个 token（信息 = v3r）；
  - **VE 臂**：再加 ≤128 个事件 token（信息 = v3r ∪ 完整事件序列）。
  头：对手 token → 听牌 logit；待牌 logit = 牌种 token · 对手 token（key-query）。损失 = 听牌 BCE + 听牌对手的待牌 BCE。同步长、同数据、同种子。
- 指标（留出局）：
  1. 默听检测：非立直对手的听牌 log-loss / AUC；
  2. 手牌危险度 AUC：对每个听牌对手，在本家手中各牌种上，用待牌概率区分"会放铳 / 不会"（决策直接相关）；分立直与默听；
  3. 待牌行内 AUC（34 种牌全集）。
  差值 VE−V 的 95% CI 用按局聚类自助法。
- 敏感度：VE、V 各在一半数据上再训一次，看差距是否随数据增大（随数据增大 ⇒ 更大模型 / 更多数据下差距可能更大）。

## Success Criteria（发射前定）
- **H1**：手牌危险度 AUC（全部听牌对手）VE−V ≥ +0.010，或默听检测 log-loss 相对降低 ≥ 2%，且 95% CI 不含 0。
- **H0**：危险度 AUC 差 < +0.003 且默听 log-loss 相对降低 < 0.5%。
- 介于二者之间 = 弱信号，不单独支撑 Rust v4 移植。

## Scope（判决范围戳）
人类 Tenhou 对局分布（人类的"破绽"与纯血自对弈不同）；4 层 d128 探针、≈数千局训练；
形式听牌标签（不含役/振听）；信息差 ≠ RL 能兑现的收益（RL 还受信号噪声限制）。
H0 只说明"在这个探针容量和数据量下事件序列没有可提取的额外信息"，不覆盖更大模型 / 自对弈分布。

## Results
全量数据（8000 局训练，1500 局留出，386,480 决策点）；A = V（v3r），B = VE（v3r + 完整事件序列）：

| Metric | V（v3r） | VE（v3r+事件） | Δ VE−V (95% CI) | 判据 |
|---|---|---|---|---|
| 手牌危险度 AUC，全部听牌对手（主指标） | 0.7506 | 0.7499 | −0.0007 [−0.0016, +0.0003] | H1 需 ≥ +0.010；H0 < +0.003 → **H0** |
| 危险度 AUC，立直对手 | 0.7269 | 0.7245 | −0.0024 [−0.0039, −0.0007] | VE 反而略差 |
| 危险度 AUC，默听对手 | 0.7686 | 0.7694 | +0.0008 [−0.0004, +0.0020] | — |
| 默听检测 log-loss（主指标） | 0.1602 | 0.1593 | −0.59% [−0.88%, −0.30%] | H1 需 ≤ −2%；H0 > −0.5% → 落在"弱"区下沿 |
| 默听检测 AUC | 0.9348 | 0.9352 | +0.0004 [+0.0001, +0.0008] | — |
| 全体听牌 log-loss | 0.1497 | 0.1489 | −0.59% [−0.87%, −0.30%] | — |
| 无条件危险度 AUC（P听×P待） | 0.9440 | 0.9441 | +0.0001 [−0.0001, +0.0003] | — |

对照尺子——**同一模型数据翻倍**（半量 4000 局 → 全量 8000 局）：

| Metric | V 半→全 | VE 半→全 | VE−V 半量 | VE−V 全量 |
|---|---|---|---|---|
| 危险度 AUC（全部） | +0.0048 [+0.0040, +0.0056] | +0.0032 | +0.0010 [−0.0001, +0.0021] | −0.0007 |
| 默听 log-loss | −1.80% | −1.99% | −0.40% | −0.59% |

训练损失终点：V 0.1383 / 0.1635（听牌 / 待牌），VE 0.1370 / 0.1637——训练集上也几乎没有差别，不是过拟合掩盖。

## Conclusion
- **判决：实质 H0，形式上落在"弱"区下沿**。主指标手牌危险度 AUC 差 −0.0007（CI 含 0，远低于 H1 的 +0.010）；默听检测 log-loss 只低 0.59%（H0 界 0.5%、H1 界 2%）。
  完整事件序列相对 v3r 平面能多提取的读牌信息，**约为数据翻倍收益的 1/3（log-loss）到 0（危险度）**；差距也没有随数据增大而扩大（危险度半量 +0.0010 → 全量 −0.0007）。
- 解读：v3r 已经编码了读牌所需的几乎全部公开信息（各家牌河的顺序 / 摸切 / 立直宣言牌 / 被鸣 / 副露类型 / 可见枚数），v3r 丢掉的"同种牌多次出现的时序"等细节对听牌与待牌判断几乎没有额外价值。
  把探针做大只受数据量限制（半→全仍在涨），**不受输入信息限制**。
- 对"更灵活的 transformer 能否抬高平台"的含义：事件序列架构**缺乏信息基础**——就算它的交互更自由，能多读出的东西也很少。平台上限更可能来自优化信号（策略梯度噪声、价值梯度主导主干、数据新鲜度），而不是"看不到"。
- **范围戳**：人类 Tenhou 对局分布；4 层 d128 transformer 探针（86.5 万参数）、8000 局（205 万决策点）训练；形式听牌/待牌标签（不看役与振听）；只测"读牌"信息（不测进攻价值判断、局况/名次判断）。
  失效条件：自对弈分布中破绽形态不同；远大于 8000 局的数据或大得多的模型可能挖出更细的时序信息；进攻侧（牌效 / 打点）不在本探针范围。
