# exp8_dnn_scratch_massive（预注册）

- **Date**: 2026-08-14  **Status**: complete（2026-08-15；两条臂各 60 万局跑满，标度曲线 4 点 + 两次直接对决全部完成）
- **用户指示**: 「继续探索 dnn 纯 rl 对局路线」+「如果用极其大量的 rl 对局减少 variance 呢」+「**不用 shaping 引导**」。
- **因此设计**: 纯自对弈、**无教师、无 PBRS 塑形**，只有真实结算奖励；唯一干预是**海量对局 + 大批量**。

## 已实测的前提（不是假设）
未训练策略 3000 局实测：
- 自然和牌率 **0.53%**（16/3000），流局 99.47%
- **92.9% 的轨迹回报恰为 0**（四家听牌状况相同的流局无点数转移）→ 有效样本量仅名义的 7.1%
- 每 256 局批次平均仅 **1.4 个**和牌事件

exp7 的崩溃机理由此确认：32 局/批时批次常常零信号，梯度即纯噪声，熵坍塌（1.79→0.375），坍塌后的疯狂副露（10.3/局）进一步堵死和牌（副露手需役），形成死循环。

## 假设
**H1**：把批量放大 32×（32 → 1024 局/iter，每次更新平均含 5.4 个和牌信号、梯度噪声降 5.7×）并配合熵正则，足以避免坍塌并让和牌率上升。
**H2（标度问题，用户核心提问）**：强度/和牌率随训练局数的增长曲线是什么形状——是持续爬升、还是很快饱和？

## 方法
- 纯 REINFORCE + 优势归一化，settlement 奖励，γ=0.995，复式牌（dup_k=4）留一基线。
- 1024 局/iter × ~976 iters ≈ **100 万局**，16 进程并行采样（实测 26-31 局/秒），预计 ~10h 本地 CPU、$0。
- 熵系数 0.03 恒定（不退火，先看能否维持探索）。
- 里程碑快照：2 万 / 8 万 / 32 万 / 100 万局 → 赛后画标度曲线。

## Success Criteria（预注册）
1. **不坍塌（门槛）**：熵全程 ≥1.0。
2. **和牌率上升（核心）**：100 万局时和牌率 ≥5%（基线 0.53%，即需 ~10× 提升）。
3. **标度曲线**：4 个里程碑各与初始策略打 2000 副 DNN-vs-DNN 竞技场（SE≈135，约 15 分钟/场），给出「训练局数 → 强度」曲线。
4. **失败同样是结论**：若和牌率停在 <2%，则给出「纯稀疏自对弈在 10⁶ 局量级不可行」的定量结论，并按实测和牌率外推所需量级。

## 设计修订（2026-08-14，全部基于实测，启动前）
1. **每轮一次大批量更新**（梯度在全部有效样本上累积），取代 ~88 次连续小步。REINFORCE 梯度只在采样策略处有效；实测 88 步/轮在**单轮内**就把熵从 2.007 打到 0.441。
2. **丢弃零回报轨迹**（用户提议）。实测随机策略下占 77% 数据但仅 2% 的 |advantage| 质量；筛前后**梯度余弦 1.000、范数比 1.0002** ⇒ 纯效率增益、零信息损失。按**有效样本数**归一化（非原始总数），使等效学习率不随流局率下降而漂移。
3. **复本数 K=4 → 8**（用户洞察：流局对学防守有用）。实测经组基线「救活」的流局轨迹：K=2 → 6.0%、K=4 → 15.6%、K=8 → **39.1%**、K=16 → 65.6%。机制：同一牌墙的复本中若有人弃和进流局、有人强推放铳，流局轨迹相对组均值获得**正优势**——这就是「不放铳有价值」的梯度来源。孤立的流局恒为 0，只有复本对照赋予它信息。
   - 反例说明：按固定比例掺入流局无效——优势为零的样本贡献的梯度精确为零。要让流局**变得有信息**，而不是让它变多。
4. **lr=1e-4**（对照 1e-3：熵崩至 0.33）。
5. 熵测量修正：梯度累积期间权重不变，原先「更新后熵」实为不同子样本的采样噪声；改为在 `opt.step()` 后于**同一批探针行**上测量。

## Conclusion
1. **H1 成立且超额**：大批量 + 零回报筛选 + K=8 复本使无教师自对弈避开退化，和牌率 0.53% → 45.8%。
2. **H2（标度形状）**：两种算法都仍在从更多对局中获益，但**边际收益差 3 倍**；REINFORCE 已现递减（638→359/翻倍），PPO 未见（917→1073/翻倍）。
3. **算法杠杆很大但会换向**：24 万局时 PPO 领先 +1785，60 万局时 REINFORCE 领先 +749。
   **交叉点在 24 万–60 万局之间**；PPO 在 240k 见顶后显著倒退（−809, p=0.0058）。
   ⚠️ 本文件早先版本据 24 万局数据写下"PPO 决定性更强"，已按全程数据更正。
4. **critic 无功**：解释方差 0.033，与本项目四次独立探针一致；PPO 的优势来自 clipping 允许的 44× 样本复用。
5. **⚠️ 方法论教训**：训练期 `win_rate` 显示 REINFORCE 走平，竞技场却测出显著增长（+568, p=0.0013）——**代理指标误导过我一次**，强度判定必须回到竞技场。
