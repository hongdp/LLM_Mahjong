## Purpose & Hypothesis
用户规则 09-25：纯血线自我提升是终极目标。九轮诊断（exp72–99）把缺口定位为：多步续打"远手时连续切安全牌并保住手牌"的价值 ≈ +250 分/决策，但任何**单步**改动 ≈0，
链只从局末往前爬到中盘（FINDINGS 09-22）。已排除：策略梯度（单步）、价值自举（无好续打可缝）、单步 PIMC 搜索与策略切换（exp86，H0）、参数噪声（未检验）、贪心续打（exp98）、
静态留牌 / 学到的危险度（exp94 附录 4 / exp99）。AlphaZero 真正的改进算子不是 exp86 的"一步 + 策略回滚"，而是**多步搜索**：搜索树自己把多步序列拼出来，其价值不依赖策略会不会执行。
**H1**：以"模式序列"为搜索空间（候选 = 接下来 h 巡自己只切现物、之后回到策略，h ∈ {0, 1, 2, 3, ∞}），K 份公开信息一致的隐藏信息采样（PIMC）配对回滚，
在每个暴露决策上按滚动时域选最优模式的当步动作 ⇒ 搜索老师在纯血桌上对 Q1x 的配对胜份 ≥ **0.53**（n ≥ 1,000 对，z ≈ 2），即搜索能只用公开信息 + 自己的回滚拿到链的钱；
随后（阶段 B）把老师蒸馏回策略网（专家迭代第 1 轮），T=0 对 bc49 ≥ 0.47。
**H0**：≤ 0.51（与 exp86 D2 的 0.5045 同级）⇒ 模式搜索也拿不到钱：要么公开信息采样的回滚噪声（SE ≈1,000/决策）盖过 +250 的信号，要么"只切现物"这一模式族本身不含钱（bc49 桌上 +19/局 的读数在纯血桌上也成立）。

## Method
- **阶段 A（本机 $0，Rust 原生，纯血桌 Q1x 坐 0 号位 vs 3×Q1x）**：`MacroSearchAgent`（新，基于 exp86 `SearchAgent`）：
  在有对手立直、自己未立直的自家弃牌决策上，候选模式 h ∈ {0,1,2,3,∞}（h=0 即策略），K=32 份 `determinize` 采样对所有候选共用（common random numbers），
  `VecEnv.from_tables` 批量回滚到局末；回滚中 0 号席按模式约束弃牌（前 h 次自家弃牌限制到对全部立直家的现物，集内按策略 logits 选；无现物则不限制），其余席位与之后全按 Q1x T=0。
  取均值最高的模式，若高出 h=0 ≥ margin（300 分）则执行该模式的当步动作，否则执行策略动作；下一决策重新搜索（滚动时域）。
  评测：同 seed 配对（有搜索 vs 无搜索，两座次对称如 exp86），share 与 mean_diff；控制 margin=∞ 必读 0.500。
  同时读**纯血桌的整段宏基线**：h=∞ 一刀切（向听≥2 时）vs Q1x，n=1,000（bc49 桌上是 +19 ± 9/局）。
- **阶段 B（条件执行，H1 时；≈$6–10，另报）**：用老师在 20 万局自对弈的暴露决策上产生目标动作，学生 = Q1x 副本做交叉熵（暴露决策）+ KL 到 Q1x（其余），终评 T=0 对 bc49 20k 对 + 半庄 1,200；
  若成立则迭代（学生成为新的回滚策略 ⇒ 搜索时域外推，链再往前爬一段）。
- **纯度**：搜索只用公开信息（determinize 只重采自己看不见的部分）、自己的策略做回滚、振听规则定义的现物集做候选生成；无外部模型、无人类数据。

## Success Criteria（预注册）
1. 阶段 A 控制 margin=∞：share 0.500 ± 0.02（框架自检）。
2. 阶段 A 主判据：搜索老师 vs Q1x（n ≥ 1,000 对）share ≥ 0.53 且 mean_diff ≥ +100/局 → H1（进阶段 B）；≤ 0.51 → H0。0.51–0.53 = 中间带：放大到 3,000 对再判。
3. 阶段 A 旁证：改判率、每决策耗时；分模式被选频率（h 分布）；纯血桌整段宏基线。
4. 阶段 B：终点对 bc49 ≥ 0.47 → 蒸馏成立；≤ 0.462 → 老师的钱蒸馏不进去（记录）。

## Conclusion
**H0**：模式序列 PIMC 搜索（候选 = 之后 h 巡只切现物，K=32–64 份公开信息一致采样配对回滚，滚动时域）在纯血桌上对 Q1x 的胜份 0.5045–0.5055，全部 ≤0.51；
mean_diff 三臂合并 +58 ± 31（1.9σ）即使为真也只有 ≈ +1 pp，远低于 +100/局 的判据。与 exp86（单步 PIMC 0.5025–0.5075、策略切换 0.5045）同一量级：把候选从「单张牌」换成「多步模式」没有让搜索看见更多的钱。
读法：①回滚噪声：K=64 时每个候选均值的 SE 仍 ≈ 600–900 分，而模式之间的真实差 ≈ 几十到两百分，22–50% 的改判大半是噪声驱动；②模式族本身：整段宏基线在纯血桌上也只有 +16 ± 39，
「只切现物」这一族的钱本来就少（bc49 的 +258 来自手型管理而非现物），搜索再准也只能在这一族里挑。**搜索式改进算子（一步 / 多步模式）在纯血线关闭**；要让搜索有效，需要更强的回滚/评估器，而那正是我们要造的东西。
