# exp4_critic 总报告（2026-08-11）

## TL;DR
两条结论方向相反，必须分开读：

1. **critic 本身失败**：价值头的样本外解释方差全程平在 **0.020**（门槛 0.2），优势方差只降 **1%**（门槛 10%）。两条预注册机制判据都不达标。
2. **但阶梯竞技场给出了本项目第一个显著强度增益**：ep40 对 SFT 锚点 **+2950 点（p=0.0027，6 场 Bonferroni 校正后仍显著）**。这是 RL 真的学到东西的首个硬证据——而它几乎肯定**不是** critic 的功劳（见下）。

## 竞技场结果（复式对局牌 × 双方向，RAW 终局点数）
| 对局 | 副数 | 配对差分 | SE | z | p | 校正后（α=0.0083） |
|---|---|---|---|---|---|---|
| critic-ep50 vs exp2-S-ep50（主判据） | 64 | +634 | 628 | +1.01 | 0.31 | 无差异 |
| stair ep10 vs 锚点 | 32 | +600 | 962 | +0.62 | 0.53 | 无差异 |

| **stair ep40 vs 锚点** | 32 | **+2950** | 982 | +3.00 | **0.0027** | ✅ **显著强于锚点** |
| stair ep50 vs 锚点 | 32 | +2147 | 927 | +2.32 | 0.021 | △ 名义显著，校正后不成立 |

**加权趋势检验**（单一检验，比 5 次独立比较更有力）：斜率 **+44.3 点/epoch**（SE 30.1, z=1.47, **p=0.14**）——方向为正、量级可观（50 epochs 累计 ≈ +2200 点），但**趋势本身未达显著**。诚实表述：确证的是「ep40 这个点显著强于锚点」，不是「强度随训练单调上升」。

## 为什么强度增益几乎肯定不来自 critic
- critic 对优势的实际改动只有 1%（adv_std_ratio 0.99），rl/ref_kl 仅 0.0066——策略更新与 exp2-S 近乎同分布。
- 主判据 critic vs exp2-S 为 null（+634±1231）：两个模型强度不可区分。
- 因此 ep40/ep50 的增益应归因于**「settlement + PPO + ref-KL 这套配置本身」**，exp4 只是第一次用阶梯 checkpoint 去测量它。

**这暴露了 exp2 的一个测量盲区**：exp2-S 只测了 ep50 vs 锚点（−27±1480，null），如果当时也做阶梯，很可能在 ep40 附近同样能看到增益。**「只看终点」会漏掉训练中途的最优点**——这是本轮最有操作价值的方法论收获。

## 一致性核查（做了，没有回避）
传递性：exp4 vs S = +634，S vs 锚 = −27（exp2 实测）⇒ 传递预期 exp4 vs 锚 ≈ +608，实测 +2147，差 +1539 = **1.14σ**（三场合并 SE≈1349）→ 噪声可解释，不构成矛盾，但也说明单场 32 副的分辨率不足以支撑强因果叙事。

另需记住 exp3 的教训：**风格指标可被模板翻 5 倍而质量不变**，所以本轮不用风格解释强度。

**待解疑点（探针进行中）**：训练内 MSE 13.6 对 Var(G)≈16-28 隐含 in-sample R² 0.15-0.5，而新样本上只有 0.02。这个落差区分两种诊断：(A) 特征无可泛化价值信号 → 必须先做 v3 富上下文；(B) 价值头过拟合 → 正则化可救。`scripts/probe_value_decodability.py`（新 rollout + **按对局切分**的 ridge）判定：ridge 测试 R² <0.10 → 诊断 A。结果补入本报告。

## 下一步建议
1. **立即可做（零成本、高价值）**：把阶梯竞技场设为所有 RL run 的标准收尾（每 10 epochs 一档 vs 固定锚点）。exp2 的 null 结论应据此**重新检验**——用它保留的 ep25/26/50 补测。
2. **critic 路线暂缓**，等探针判定：若诊断 A，则 v3 富上下文是 critic 的前置条件，顺序必须是 v3 → critic。
3. 强度峰值可能在训练中段（ep40 > ep50）：需要更密的阶梯 + 更多副数确认是否存在过训练衰减。
