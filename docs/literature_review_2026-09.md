# 文献对照：我们的提升空间在哪里（2026-09-03）

> 三路并行检索（麻将 AI 系统 / 不完全信息博弈中"人类先验 + RL"的方法学 / BC 数据缩放与增广），
> 逐条对照本项目实测（exp45/46/49/55/56/59/60/61/62）。数字均带出处；查不到的明说"未找到"。
> 本项目现状：2M ConvFormer `bc49`，18.4k 凤凰卓局 ≈ 12M 决策，全类型 top-1 0.806；部署刻度与 Mortal 打平
> （半庄 n=1200，share 0.4771±0.0144，pt −0.36±0.42）；所有 RL 变体（PPO+锚、联赛、Double DQN+DQfD 锚）= BC 水位；
> 每决策回报噪声 ≈ 动作价值差的 50–100×；花色对称测试时平均零效应（exp61）、训练时增广 +0.05pp / 头对头 0.5025±0.0035（exp62）；
> 同配方重跑的训练级噪声地板 ±0.5–0.9% 胜份（exp62 控制臂 vs bc49 原版 0.5059）。

## 1. 最强系统做了什么、我们没做什么

历史 SL 切牌精度阶梯：Mizukami 2015 62.1% → Matsuda 2021 63.5%@0.8M → Gao 2019 70.4%@2.1M → Suphx 76.7%@15M。
**我们的 0.806 混入了 85–95% 可预测的鸣牌/pass 头，要报"仅切牌、去掉立直后强制切"的精度才能与 76.7% 比。**

我们没做的（按证据强度）：①隐藏信息进 critic（Suphx oracle guiding / RVR / PerfectDou 都有消融数字）；②GRP 式顺位价值奖励
（Mortal 的整套目标是顺位 EV，不是分数）；③决策时搜索 + 蒸馏回网络；④百万级复式评测；⑤10× 数据。

## 2. "人类先验 + RL 超越人类"在别的博弈里怎么成的

| 系统 | 先验→RL 后 | 先验怎么保住 | RL 规模 | 对我们的含义 |
|---|---|---|---|---|
| AlphaGo | SL 57% top-1 → RL 策略 80% 胜 SL | 无 KL，靠搜索用 SL 网 | 30M 自对弈局 | 完美信息、双人、高信噪比 |
| AlphaStar | SL 3699 MMR → 6275（宗师） | **KL 到 SL 策略** + 人类开局统计伪奖励 + 联赛 | 600 智能体 × 14 天 × 16 TPU | 10³–10⁴× 我们的算力 |
| Diplomacy piKL/Diplodocus/Cicero | 模仿 13.4% → piKL 32.9% 对人群；DORA（无锚 RL）第 32 名，Diplodocus 第 1 | **KL 锚 + 决策时搜索**（λ·KL 进效用） | 未公开 | **7 人隐藏信息**里唯一超越模仿的路径 = 锚定搜索；无锚自对弈**不如 BC** |
| Suphx | SL → RL-2（仅箱线图） | 仅初始化 + 短 RL；无 KL | 1.5M 局 × 44 GPU / 头 | 需要 oracle critic 才稳定 |
| Mortal | 离线 Q → 在线 +0.6 pt/局 | 离线 CQL 保守 | 50 万半庄 | 离线阶段贡献了绝大部分 |
| DouZero/PerfectDou | 从零 > SL(226k 人类局) | 无 | 4×1080Ti × 30 天 | 完美信息 critic：+0.04 胜率、4× 样本效率 |

离线 RL 理论（Kumar et al. ICLR 2022；Rajaraman NeurIPS 2020；Levine tutorial）：**专家数据近似确定性（覆盖 C*=1）时，
离线 RL 与 BC 同阶，没有可利用的反事实**。这正是 exp59/60 的现象（DQfD 锚 + TD 收敛到 BC 排序）。
ICLR 2026 大规模比较（5600 runs）：PPO/MMD 不输 R-NaD/NFSP/PSRO —— 我们的 PPO 平台不是算法选型问题。

## 4. 对照我们的实测，提升空间排序

1. **数据 10×（20 万局）**：唯一有本项目内实测斜率（exp49）且供给存在的杠杆。预期 +3pp 左右精度，按凸性折算 ≥ +30–60 Elo。
   工程前提：回放管线 3–5× 优化或流式 uint8 缓存（200k 局 × 56×34 B ≈ 230GB，不能整份物化）；遵守天凤 `/sc/raw/` 规则
   （单会话、≥20 分钟轮询、只取 .log.gz、不再分发）。费用量级：L40S 上 25k 样本/s → 120M 决策/epoch ≈ 80 分钟，10 epoch ≈ $15。
2. **目标函数：顺位 EV 而不是分数**。Mortal 首位率 29.8% vs bc49 20.2%（600 席）而总 share 打平，说明两者在优化不同的东西。
   第一步 0 元：把现有梯子按天凤 pt（+90/+45/0/−135）重算（`play_pair_vector` 行已带 uma）。若 Mortal 在顺位刻度显著领先，
   BC 的天花板不是麻将上限，而是"人类平均在分数刻度上的像"。
3. **全量预训练 → 高分席位微调**（SC2 +105 Elo 的同数据唯一游戏内证据）：解析牌谱头的各席 R 值，微调一遍，n=4000 配对评测。几小时。
4. **搜索 → 蒸馏**（>+100 Elo 证据的唯一路径）：用向量化引擎（300 局/s）+ 采样隐藏牌 + bc49 rollout 给"争议决策"
   （top-2 间隔 <1.0，占 26%，exp61）标注动作价值，蒸馏进 Q 头/策略。先做 1 万决策的试点看标签信噪比，再决定规模；
   需要信念模型（先用"未见牌均匀"近似，承认 PIMC 弱点）。
5. **RL 的前置条件**（在 1–4 之前不再烧 RL）：①critic 看牌山与对手手牌（Suphx/RVR/PerfectDou 三处消融为正）；②GRP 式局级奖励；
   ③配对牌山 + 价值网控制变量（AIVAT/MJ-DL VAT −45.5% 方差）；④评测规模到 10⁵–10⁶ 复式局，否则测不出 +0.5% 量级的真实增益。
6. **不要再做**：回报条件 BC；更多花色增广/TTA；无数据扩容的更大模型（exp49 三次阵亡）；无锚自对弈（DORA 第 32 名）。
