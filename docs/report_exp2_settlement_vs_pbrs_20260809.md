# exp2_settlement_vs_pbrs 总报告（2026-08-09）

## TL;DR
纯结算奖励（S）与能量一致 PBRS（P）在完全相同的条件下（PPO + ref-KL 0.05 + γ0.995 + 50×12 + 同 SFT 锚点 + post-audit 引擎）各训 50 epochs，**竞技场三场判定全部无显著差异**：S vs P、S vs 锚、P vs 锚的配对差分 95% CI 全含 0。结论与 exp1 一致并更干净：**当前瓶颈不是奖励设计，是信用分配的方差——下一步是 critic value head**。

CI 宽度 ±1500-1800 点 vs 差分绝对值 <520 点：即使真有效应，也远小于本量级下可检出的最小效应。方差分解（起手 Φ₀ 仅解释结算方差 2%）早已预言此格局。

## 意外发现：风格大迁移与强度脱钩（H3 证伪）
末 5 epochs 风格探针（60 局/臂，只计 action XML 标签）：

| | riichi/局 | 副露/局 | 和牌局率 | 放铳局率 |
|---|---|---|---|---|
| Arm S | 0.48 | **6.02** | 71.7% | 65.0% |
| Arm P | 1.02 | 1.90 | 68.3% | 53.3% |

预注册 H3 预期「无稠密塑形 → 无风格迁移」——**结果相反**：S 臂在稀疏零和信号下长出极端副露风格（6 副露/局，立直减半），P 臂反而更接近 SFT 风格。两个推论：
1. **风格漂移不是塑形通道独有**。稀疏噪声信号下 PPO 同样会漂移，方向由噪声梯度的随机游走决定。
2. **token 级 ref-KL 锚不约束行为分布**：S 臂 ref_kl 只有 0.023（P 臂 1/5）却行为迁移最猛——每步 token 分布贴着参考，但被采样出的动作序列在博弈层面走到了完全不同的地方。锚在错误的抽象层上。
（局限：anchor 在当前引擎下的精确风格基线未提取——P 臂数值接近 exp1 时代锚点风格，S 臂离群是稳健结论。）

## 结论与下一步
1. **奖励设计路线（settlement vs PBRS）在当前方差水平下不可区分**——两者都不产生可测强度。停止在奖励端继续投资。
2. **critic value head 是指认的下一步**（方差分解 + 本实验 CI 宽度双重证据）；配套「训练内锚定竞技场」（每 10 epochs 16 副复式 vs 锚点）实现早停止损。
3. 行为层锚定问题（token-KL 不约束风格）记入 v3 设计考量：若需要风格稳定，锚必须作用在动作分布/事件频率层。
4. 基建：本轮起 flex-start 临时机全流程验证（3 次发射教训固化 SKILLS.md）；exp3_nothink（think 消融，2-3× rollout 提速）已立项在跑。
