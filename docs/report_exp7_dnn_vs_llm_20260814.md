# exp7：传统 DNN 基线 vs LLM Agent（2026-08-14）

## 为什么做这个
此前项目里所有强度都只相对自己的 SFT 锚点度量（RL 增益约 +1000 点），**没有外部尺度**判断这个数值算强还是弱。传统 DNN agent 提供这把尺子：同一引擎、同一复式牌竞技场、同一个 SFT 锚点做对手。

## 一句话结论（2026-08-15 公平性对照完成后定稿）
**按数据量对齐，两种架构打平；按成本算，传统方法碾压。**
语料量对齐时（各 200 局教师数据），1.4M 参数 CNN 对 LLM 的 SFT 锚点是 **+308 ± 806（p=0.45，无显著差异）**；
教师复现率在同为贪心解码时也几乎持平（62.8% vs 59.2%）。
但当允许 DNN 吃下 250 倍教师数据（它只要 1 小时本地 CPU），它就变成 **+1129 ± 869（p=0.011）显著更强**——
与 LLM 花 27 小时 A100 强化学习换来的 +1076 完全同量级。
**⚠️ 修正**：本报告初稿的头条"传统 DNN 显著更强"当时只有大语料臂的数据，现已被语料对齐臂推翻——
那个优势来自数据预算，不是架构。

## 主结果表：全部相对同一个 SFT 锚点
| Agent | 相对锚点差分 | p | 训练成本 | 备注 |
|---|---|---|---|---|
| LLM + 50 epochs RL（exp4 汇总 7 个 checkpoint） | **+1076 ± 753** | 0.005 | 27h A100 ≈ $45 | 见 exp5 报告 |
| **DNN-BC（3000 局教师语料）** | **+1129 ± 869** | 0.011 | **~1h 本地 CPU** | 语料量是 LLM 的 ~250 倍 |
| **DNN-BC（语料量对齐 200 局）** | **+308 ± 806** | **0.45** | ~4 分钟 | ✅ **公平性对照：无显著差异** |
| DNN-BC→RL vs DNN-BC | +324 ± 855 | 0.46 | +72 分钟 | RL 对传统 agent 同样收效甚微 |

**这四行合起来的读法**：把教师数据量拉平，架构差异就消失了（+308，p=0.45）；
差异出现在"谁能吃下更多数据"——而这是成本问题，不是能力问题。

## 教师复现率：同一批 500 个留出决策点
| 采样方式 | DNN（语料对齐 200 局） | LLM SFT 锚点 |
|---|---|---|
| **贪心** | **62.8%** | **59.2%**（非法 0%） |
| 各自出牌温度 | 59.6%（T=1.0） | 49.8%（T=0.9，非法 **1.0%**） |

**这张表推翻了一个直觉结论**：初看（59.6% vs 49.8%）像是小 CNN 明显更会学教师；但把解码方式也对齐后只差 3.6pp。**LLM 在 T=0.9 下比贪心损失约 9pp 决策质量**——这既是竞技场里 LLM 的一部分劣势来源，也说明低温评测是一项被低估的免费改进（同时也是 exp5 指出的降方差手段，现已把温度参数化）。

## 三个跨架构复现的现象（比强弱对比更有价值）
1. **RL 增益都小到勉强测得出**：LLM +1076±753、DNN +324±855。「在模仿之上做稀疏奖励 RL」的低收益不是 LLM 特有问题。
2. **同样的副露漂移**：DNN 做 RL 后副露 1.72→4.06/局（2.4×）而和牌率纹丝不动（0.844→0.844）；LLM 侧在 exp2/exp3 出现过同样模式。参数量差 1400 倍，漂移方向一致 → 这是稀疏零和奖励 + 策略梯度的共性，不是模型的毛病。
3. **纯自对弈都会退化**：DNN-scratch（无教师）20 iters 内熵 1.79→0.375、和牌率 0%、副露 10.3/局，即典型「臭棋篓子」局部最优。LLM 侧靠 SFT 先验才避开——这从反面确认了模仿初始化的必要性。

## 必须声明的不对称（是事实，不是缺陷）
1. **DNN 结构上不可能打出非法动作**（动作头被 mask）；LLM 在 T=0.9 下有 1.0% 非法率。这是传统架构的真实优势。
2. ~~**语料预算**未对齐~~ → **已补测并推翻头条**：语料对齐臂（200 局）vs 锚点 +308 ± 806（p=0.45）。
   主判据的 +1129 来自 250 倍的数据预算，不是架构优势。
3. **解码温度未对齐**（LLM 0.9 / DNN 1.0，各按自身训练温度）。已参数化，待做温度对齐复测以分离「架构差异」与「解码差异」。
4. **信息公平已刻意保证**：DNN 编码器只暴露 LLM prompt 里有的信息，不含引擎算的向听/受入（有测试锁定）。

## 这对项目路线意味着什么
- **同等数据下两者没有差距**：LLM 的 2B 参数与预训练先验，在这个任务上并没有换来更高的样本效率——
  1.4M 的 CNN 用同样 200 局教师数据达到统计上无法区分的强度。
- **差距全在成本曲线上**：DNN 每分钟 267 局、教师数据可任意加、一次实验 1 小时 $0；LLM 每分钟 0.37 局、
  一次 RL run 27 小时 $45。**若目标是"打得好"，传统方法性价比碾压——不是因为它更聪明，而是因为它便宜到可以多喂。**
- **值得继续投 LLM 的理由必须是别的**：自然语言可解释性、零样本迁移到规则变体、与人类交互——这些需要单独立项验证，不能靠棋力论证。
- **RL 阶段的边际收益在两种架构上都很低**：下一步的杠杆更可能在"更好的模仿目标"（更强的教师、搜索蒸馏）而非"更多 RL"。
