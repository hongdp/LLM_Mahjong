## 并行与合成
- 第一批（纪元 3 重校后立刻发射，5 个 run，g2-standard-32 × 5 或分两波）：exp27 A/B/C + exp28 A′/A″（A 共享）。
  每 run ≈ 700k–1M 局 ≈ 5–7 h。
- **合成规则**：架构（exp27 最优）× 训练配方（exp28 最优）不能假定可加——exp20 已证明 GAE×ConvFormer 不可加。
  因此第二批 = **一条合成确认 run**（最优架构 + 最优配方，从零），与两条单变量最优直接对打；
  只有合成 run 显著 ≥ 两者时才定为新冠军配方。
- 多局结构是引擎变更（纪元 4），**不与第一批并行**——它会让所有锚点再次作废；放在第一批结论之后。

## 附：随机性与熵的路线（2026-08-23 用户同意）

目标：让策略的随机性**跟着价值差走**（等价动作平分、明显优劣几乎确定），而不是被全局熵奖励均匀软化。

| 步 | 实验 | 内容 | 判据 |
|---|---|---|---|
| 0 | 探针（先做，只读） | **条件熵探针**：按"最优两动作的 V/Q 差"分桶，画每桶策略熵；高手形态 = 单调下降曲线 | 冠军基线曲线；exp28/29 共用判据 |
| 1 | exp28（进行中） | A″ 熵计划更早更低；A′ 低熵 + 混合温度（探索挪到采样侧，行为 logprob 修正） | T=0 Elo 不降、贪心−采样差距减半 |
| 2 | 下一批 | **目标熵控制**（`--entropy_auto --entropy_floor`）：0.5 起线性降到 0.25；另一臂 **0.2 恒定**（探"训练期熵下限"） | 过早收敛信号：decisive 卡住、KL→0、Elo 平台低 |
| 2 | 下一批 | 规模/架构臂 × 低熵或目标熵（C/B 在冠军配方下被熵按住） | 与 A 同步的 decisive 斜率；熵平台不高于 A |
| 3 | exp29 | **参照 Boltzmann(Q/τ) 的正则**（KL(π‖softmax(Q/τ)) 替代均匀熵）或 Q 推导的 actor（最大熵 RL / Q-actor-critic） | 条件熵曲线单调下降；Elo ≥ 基线 |
| 4 | 持续 | 联赛/种群保留：博弈论意义的混合策略（隐藏听牌形）只有在被剥削时才有收益 | 剥削赛不被任何历史版本打穿 |

理解：熵 H（nat/决策）= ln(有效动作数)；均匀 ≈2.3，冠军平台 1.04（≈2.8 个动作在摇），exp25 证明 H≈0.77 的随机性已在花钱；
人类高手 ≈0.2 是**条件熵的平均**（明确局面 0、两可局面 0.7），不能当训练初期的全局目标。

## 附：能力出场顺序假设（用户观察 2026-08-23）
前期和牌率与和牌速度最能反映模型能力（立直、保门清都是做牌效率的手段）；防守要到后期才"轮到"，用放铳率观察。
可追踪量（每里程碑 ckpt，`eval_style_profile` 已加 **和牌巡目 / 放铳巡目**）：和牌率、和牌巡目、立直率、副露率、放铳率、放铳巡目。
判定"攻守转换"：放铳率开始下降而和牌率基本不降（若两者同比例下降只是变保守）；正式读数用对固定锚点的对局而非镜像自对弈
（放铳率是生态量）。人类对照：玉之间 和牌 22–25% / 放铳 11–13% / 立直 ~20%。
