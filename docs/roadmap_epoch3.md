## 并行与合成
- 第一批（纪元 3 重校后立刻发射，5 个 run，g2-standard-32 × 5 或分两波）：exp27 A/B/C + exp28 A′/A″（A 共享）。
  每 run ≈ 700k–1M 局 ≈ 5–7 h。
- **合成规则**：架构（exp27 最优）× 训练配方（exp28 最优）不能假定可加——exp20 已证明 GAE×ConvFormer 不可加。
  因此第二批 = **一条合成确认 run**（最优架构 + 最优配方，从零），与两条单变量最优直接对打；
  只有合成 run 显著 ≥ 两者时才定为新冠军配方。
- 多局结构是引擎变更（纪元 4），**不与第一批并行**——它会让所有锚点再次作废；放在第一批结论之后。
