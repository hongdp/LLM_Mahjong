# HandRiverFormer（exp30）——设计定稿（用户审阅通过 2026-08-23）

两序列注意力模型：**手牌实例 token 作为 query，cross-attend 牌河事件序列**。
盘面 CNN 完全移除；信息严格 = v3 公开记录（零派生特征）。

## 序列与 token
**手牌序列（≤20 槽 = 18 实 token + CLS）**：门清手牌（≤14）+ 自家副露牌（≤16，属性旗标注；
两者此消彼长，仅含杠时总数超 14，上界 18——用户校正，勿再用 32 槽上界）。
token = 共享正弦 rank PE（1..9，跨花色共享，经投影）+ suit emb + honor emb + copy emb + 属性投影[红五, 在副露]。
无位置编码（集合）；自注意力带 rank 相对偏置（20 桶）。

**上下文序列（≤128 事件 + 全局 token）**：
- 弃牌事件：牌面因子化 + 相对座位 emb + **绝对巡目正弦 PE** + **新近度正弦 PE**（recency=0 即最新弃牌）
  ——两个正弦经**各自独立的投影**相加（用户要求：两正弦不得共享频率维度；可学习 emb 直接相加无妨）
  + 属性[摸切, 立直宣言, 被鸣走, 红五, **最近弃牌旗**]；
- 对手副露 token（kind=1，含来自我旗）、宝牌指示 token（kind=2）；
- 全局 token：v3 标量组（点数/供托/风含西场码/余牌/立直旗+巡目/弃牌计数）线性投影。

## 主体与头
d=320、8 头；上下文自编码 2 层；手牌主干 8 × [自注意力(rel-bias) → cross-attn(Q=手, KV=事件) → FFN(4d)]，
全 pre-LN；头 = [CLS ‖ 手牌均池 ‖ 上下文均池] → MLP(512) → 374 动作 logits（零初始化）；V 头同源 → 256 → 1。
参数 23.2M。

## 基建
编码器变体 **v4** = v1r 的 21 平面 + 31 个"伪平面"打包的事件缓冲（128×8 特征 + 长度头），
共享内存 RPC / 向量化 worker / 训练器零改动。本地实测 48.6 局/s（24 worker × K32）。

## 消融开关
`no_cross`（上下文均池拼接替代交叉注意力）、`no_temporal_pe`（去两个时间 PE）、`free_rank_emb`（自由查表 rank）。

## 发射条件与判据（预注册见 experiments/exp30_hrf_prereg）
第二批胜出配方；对照同配方 cnn_m_r；Elo T=0 ≥ 对照 −10 为"可平替"；重点维度 = 对锚点放铳率 / defense_iq
（事件流为读牌设计）；拆分探针、条件熵曲线形状；吞吐门 G4 ≥ 35 局/s。
