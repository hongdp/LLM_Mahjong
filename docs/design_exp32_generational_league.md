# exp32 — 跨代联赛（PSRO-lite）：多 agent 循环迭代配方（设计定稿待审）

> 动机链：防守悖论（payoff 时机 × 探索窗口错位）→ 熵高原只保数据、强对手只在后期出现 →
> 让**强对手出现在孵化期**的唯一纯度合规方式 = 新一代从零训练、从第 1 局起面对历代冻结冠军。
> 理论定位：policy-space 迭代最优响应（PSRO 的轻量实例化）；与 AlphaZero 的分野 = 无搜索改进算子，
> 用"代际重启 + 熵高原 + 累积池"三件套代偿（见论文 draft §6/§9）。

## 1. 配方形式化

**状态**：冠军谱系 C = [G0, G1, …]（冻结 checkpoint），纪元池（Elo 锚点）。G0 = exp27-A。

**第 k 代训练**（k ≥ 1）：
- 初始化：**从零**（重置可塑性 + 完整熵高原；exp22 已证 warm-start 联赛无效）。
- 对手构成（每局按 deal seed 确定性采样，复用 exp22 的 `league_plan` 机制）：
  - **50% 镜像局**（4 席都是学习者）——攻击技能不退化、防对手池把课程压成全输；
  - **50% 联赛局**：学习者随机 1–2 席，其余席位从池 C 均匀采样（k≥3 后改 PFSP 加权：按对学习者的胜率
    加权采样，重点打"打不过的"）。只收学习者席位的轨迹（learner-only episodes，机制现成）。
- 配方：冠军配方不动（PPO/GAE/dup_k=8/熵 0.03×600k→0.01/T=1），1.0M 局，v1r/374，纪元 4 引擎。
- 基建：`--league --league_frac 0.5 --gpu_infer --gpu_infer_opponents`（池模型 GPU 托管，多 model_id）
  ×向量化 worker——**发射前必须过基建冒烟**（向量化路径 × 联赛路由是新组合）。

**晋升门**（全过才入池成为 G_k，否则记 null 并诊断）：
1. Elo（纪元池，T=1）≥ 上一代冠军 − 10；
2. **剥削赛**：贪心 100 副对池内每一员，无一显著为负（"不被任何历史版本剥削"）；
3. 探针无退化：拆分一致率 ≥ 上代 − 3pp。

**每代必录指标**（防守是本实验的主要观测）：
defense_iq、对锚点贪心放铳率/和牌率/巡目、v_danger_gap（按起始顺位分桶）、条件熵曲线形状、
风格轨迹（TB style/*，重点看联赛局比例下的立直/副露演化）、对池各员的分差矩阵。

**停机规则**：连续两代防守指标无进展且 Elo 增益 < 15 ⇒ 暂停迭代，转入变量诊断
（league_frac↑ / PFSP / 顺位奖量纲 / 熵回火臂）。

## 2. 实验臂（第一期 = 第 1 代 + 对照）

| 臂 | 内容 | 作用 |
|---|---|---|
| 主臂 gen1 | 上述配方，池 = {exp27-A} | 核心假设检验 |
| 对照 | **臂 5（已完成）**：同配方纯镜像 × 纪元 4 = 1031.9 | 同代同纪元基线，联赛的增量=gen1−臂5 |
| 参照 | exp22-r2（warm-start 联赛）诸指标 | 历史负对照（时机错位的实证） |
| 备用臂（主臂有信号才跑） | gen1 + 熵回火（700k 处 0.01→0.03×100k→0.01） | 叠加检验"后期重开探索"的边际 |

## 3. 判据（预注册）

- **H1（防守涌现的首个信号）**：gen1 的 defense_iq ≥ 0.05（历代全部 ≤0.021）且对锚点贪心放铳率比臂 5 低 ≥ 1.5pp。
- **H2（强度不受损）**：gen1 Elo（T=1）≥ 臂 5 + 15（联赛应净增益；若 < 臂5 − 15 判失败）。
- **H3（对池不可剥削）**：晋升门 2。
- 机制旁证：联赛局中对 A 的放铳率随训练下降的斜率（TB 可看）；v_danger_gap 领先桶 > 落后桶。

## 4. 预算与时间表
每代 1.0M 局 ≈ 85–110 min（g4-flex，联赛局的对手 GPU 前向增加 ~20% 开销）≈ **$4/代**；
第一期（gen1 + 可选熵回火臂）≤ $10。第二期（gen2/gen3）按第一期结果再批。

## 5. 风险与预注册的诚实条款
- 联赛×向量化 worker 是新组合：冒烟不过则修基建，不改设计。
- 若 gen1 强度达标但防守仍 ≈0：单局顺位压力 + 强对手仍不够 ⇒ 主嫌疑转向"防守 payoff 的量纲"
 （顺位奖 ±2 相对大牌 ±8~12 偏小）——预注册允许第二期加"顺位奖 ×2"臂，但不得中途改第一期。
- 若 gen1 Elo 大幅低于臂 5：对手过强导致学习信号塌缩 ⇒ league_frac 降 0.25 重跑（记为 gen1b）。
