# 竞技场 Elo 锚定评分体系（League Rating）

2026-08-16，源自用户提议：「用之前训练出来的标准模型的强度作为基准，衡量新模型训练中的强度」。

## 动机：两两对决协议的三个缺陷

现行协议（200 副复式配对竞技场，报配对分差 ± 95% CI）在单个假设检验上是对的，但作为
**强度度量体系**有缺陷：

1. **无公共标尺**。exp9 的 +1802 和 exp12 的 +1073 不可直接比较（对手不同）；
   「冠军」只能靠击败上任冠军的链条维护，链条一断（null 结果）就没有读数。
2. **每次评估都要挑对手**。挑得太弱/太强都浪费统计功效（差距大时 CI 相对差距小，
   但对「当前梯队内排位」无信息）。
3. **训练中无强度轨迹**。train_log 里的自对弈 win_rate 是动力学指标不是强度指标
   （对手是自己，水涨船高）；里程碑 checkpoint 的真实强度要等训后竞技场才知道。

## 设计

### 评分模型

- 每副复式对局（双方向配对）产出一个胜负记号：`s = 1 if diff > 0, 0.5 if diff == 0, 0 if diff < 0`。
  用 sign 而不是分差幅度：Elo 的 Bernoulli 似然只吃胜负；分差幅度另行保留在原始 JSON 里
  （现行协议不废除，主判据仍可引用分差 CI）。
- 期望胜率 `E = 1 / (1 + 10^((r_b - r_a)/400))`（标准 Elo 逻辑斯蒂标度）。
- **不用增量更新（K 因子），用 MLE 批量拟合**：评估是离线批量的，没有理由引入
  路径依赖。候选分 `r_c = argmax Σ [s·ln E + (1−s)·ln(1−E)]`，锚点分固定；
  SE 由 Fisher 信息 `I = (ln10/400)² Σ E(1−E)` 给出。

### 锚点池（冻结、只增不减）

| 锚点 | checkpoint | 身份 |
|---|---|---|
| `bc_cnn` | arch_sweep/models/cnn_m.pt | BC 起点（**定标原点，固定 1000 分**） |
| `rf600` | dnn_scratch_massive_20260815/games_600000.pt | REINFORCE 600k |
| `ppo44_240` | dnn_ppo_massive_20260815/games_240000.pt | exp8 时代 240k 峰值 |
| `ppo44_600` | dnn_ppo_massive_20260815/games_600000.pt | 过度复用倒退终点 |
| `reuse11_600` | dnn_ppo_reuse1_20260815/games_600000.pt | exp9 冠军 |
| `e700` | dnn_exp12_E_20260816/games_700000.pt | 现冠军（熵退火） |
| `vit240` | _cloud_ckpts/dnn_vit_rl_r4/games_240000.pt | exp10 毕业生（异架构） |

- 锚点分数由**一次性联合校准**产生：池内全循环赛（21 对 × 200 副，DNN-vs-DNN 本地
  ~2 min/场），联合 MLE（`bc_cnn` 钉死 1000 定标），此后**永久冻结**。
- 新锚点（如未来的 vit-700k）加入时：与 ≥3 个现役锚点各打 200 副，只拟合新锚点分数，
  老锚点分数不动——保证历史读数永不漂移。

### 评估协议

- **训后正式评分**：候选 vs 全部 7 锚点各 100 副（≈15 min 本地）→ 报 `Elo ± SE`。
- **训练中轻量轨迹**：每个里程碑 checkpoint vs 3 个梯度邻近锚点各 60 副 → Elo 曲线，
  与 train_log 的自对弈 win_rate 并排看。
- 种子协议：每次评分用新鲜 `seed0`（记录在结果 JSON），复式配对协议不变。

### 已知陷阱（诚实声明）

1. **非传递性**：自对弈种群可能剪刀石头布。对策：多锚点拟合 + 报告每锚点残差
   （实际得分 − 期望得分）；残差系统性超出 2σ 时提示该候选对特定锚点有克制关系，
   Elo 单值不可尽信。
2. **锚点池代表性**：全池同源（同一引擎、多数同架构 cnn），对未来风格迥异的策略
   （如门清型）可能整体失准——这正是保留分差 CI 原始协议做主判据的原因。
   **Elo 是仪表盘，预注册主判据仍是判决书。**
3. sign(diff) 丢掉分差幅度信息 → 同样 200 副下 Elo 的分辨率可能低于分差 CI；
   校准后用历史对局反推经验换算（Elo 差 ↔ 分差）标注在校准报告里。
